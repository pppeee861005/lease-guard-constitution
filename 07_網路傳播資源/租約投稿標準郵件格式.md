## 📝 郵件主旨標準格式

### 格式規範
```
【租約投稿】[城市/地區] [類型] [簽署年份]
```

### 說明
- **【租約投稿】**：固定標籤，便於系統篩選和分類
- **[城市/地區]**：租約涉及的城市或行政區（如：台北市、新竹市、高雄市）
- **[類型]**：租約類型，選項如下：
  - 整層住宅
  - 套房
  - 雅房
  - 包租代管
  - 其他（如為其他類型，請具體說明）
- **[簽署年份]**：租約簽署的年份（如：2024年、2023年）

### 主旨範例
```
【租約投稿】台北市 套房 2024年
【租約投稿】新竹市東區 整層住宅 2023年
【租約投稿】高雄市 雅房 2025年
【租約投稿】台中市 包租代管 2022年
```

## 📎 附件要求

### 必須附件
```
✅ 租約檔案（以下任一格式）：
   - PDF（掃描版）
   - 圖片檔（JPG/PNG）
   - Word 文件（.docx）
   - Open Document（.odt）
   - 純文字（.txt）

建議：
- 掃描清晰度應達 300 DPI 以上
- 照片應在良好光線下拍攝（避免模糊或陰影）
- 多頁合約應分別掃描或完整拍照

⭐ 重要提醒：
投稿前請自行刪除個人信息！
這樣可以保護你的隱私，也加快我們的處理速度。
```

### 你需要自行刪除的信息

請在投稿前刪除以下信息：

```
✂️ 請你自行刪除的項目：
  - [ ] 雙方簽署人的全名
  - [ ] 身份證號（全部或部分）
  - [ ] 電話號碼
  - [ ] 完整地址（保留地區如「台北市大安區」，刪除門牌號等詳細位置）
  - [ ] 簽名或印章
  - [ ] 銀行帳號（如果合約中有提及）
  - [ ] 其他個人識別信息

✅ 保留的信息（我們需要的）：
  - 簽署日期
  - 租賃類型和金額
  - 房屋描述（地區層級）
  - 租期長度
  - 各項費用（租金、押金、水電費等）
  - 條款內容（我們要研究的核心）

🔒 流程很簡單：
1. 你收到租約檔案
2. 打開 PDF/Word，刪除上面列出的個人信息（5分鐘完成）
3. 寄送刪除後的乾淨版本
4. 我們接收並直接進行分析，無需再檢查
```

## 🆘 常見錯誤 & 如何避免

### ❌ 錯誤 1：過度擔心個人信息（常見誤區）

**誤區**：「我要不要先把名字和電話刪掉再寄？」

**實際上**：
- 不用刪！可以原封不動直接寄送
- 包含所有原始個人信息也沒關係
- 我們會由專業團隊負責刪除

**為什麼不用你自己刪除？**
- ✅ 我們有標準化流程，刪除更徹底
- ✅ 你不用動手，節省時間
- ✅ 減少中途洩露風險
- ✅ 展示我們真的只要租約內容

**簡單說**：
把你的原始租約寄來，我們會專業處理隱私問題。你只需要填寫投稿表單即可。

### ❌ 錯誤 2：郵件主旨不標準

**問題**：主旨寫「租約分享」、「求幫助」等，不符合格式

**影響**：
- 郵件可能被誤分類
- 處理速度變慢

**避免方法**：
- 嚴格按格式：【租約投稿】[地區][類型][年份]
- 複製粘貼下面的模板，填入你的信息

### ❌ 錯誤 3：未填寫確認事項

**問題**：沒有勾選三項確認事項

**影響**：
- 無法確認你同意隱私和使用條款
- 必須回信要求補充

**避免方法**：
- 在 PDF 或回信中用 ☑ 或 [X] 明確勾選
- 或在郵件內容中寫「我已同意所有條款」

### ❌ 錯誤 4：檔案品質太差

**問題**：掃描/拍照太模糊，無法辨識條款

**影響**：
- 無法準確驗證租約內容
- 可能需要重新提交

**避免方法**：
- 使用掃描機（300 DPI 以上）
- 或在亮度足夠的環境用手機拍照
- 測試檔案：自己先看一遍，確認清晰可讀

### ❌ 錯誤 5：郵箱地址寫錯或未留下聯絡方式

**問題**：我們無法回信寄送掃描報告

**影響**：
- 你收不到報告

**避免方法**：
- 仔細檢查郵箱地址是否正確
- 務必留下有效的回信郵箱
