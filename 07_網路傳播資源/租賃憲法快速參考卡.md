## 📌 23點租賃憲法 - 核心檢查清單

### 🏘️ **第一部分：基礎資訊（第1-5點）**

- [ ] **第1點** 房屋地址完整（含樓層、門牌號、公設編號）
- [ ] **第2點** 租賃期限明確（起終日期）
- [ ] **第3點** 月租金金額清晰
- [ ] **第4點** 押金金額與返還條件
- [ ] **第5點** 租金給付方式、期限、帳戶資訊

### 💰 **第二部分：費用與金流（第6-7點）⚠️ 高風險區**

#### **第6點：電費條款 - 必檢！**
- [ ] 電價標準清楚（用瓦斯爐還是電磁爐？季節費率？）
- [ ] 超過標準用量時如何計算？
- [ ] **禁止項目**：禁止換房東自定價格 / 禁止代扣代繳（應直接繳台電）
- [ ] 每月電費帳單核對機制

#### **第7點：其他費用**
- [ ] 水費如何分配（是否含在租金內？）
- [ ] 瓦斯費（如有瓦斯爐）
- [ ] 管理費、清潔費（清楚說明誰負責）
- [ ] 網路費、停車費

### 🏠 **第三部分：權利與義務（第8-13點）**

- [ ] **第8點** 能否養寵物？（明確說明）
- [ ] **第9點** 能否轉租或轉借？
- [ ] **第10點** 裝修規則：能否換門鎖？釘牆？牆面顏色？
- [ ] **第11點** 修繕責任：房東負責什麼？
- [ ] **第12點** 承租人維護義務（保持清潔、定期檢查）
- [ ] **第13點** 電費資訊公開義務 ⚠️ **新增 114年修正**

### ⚖️ **第四部分：糾紛預防（第14-18點）**

- [ ] **第14點** 遷入時檢查清單完整（拍照存檔！）
- [ ] **第15點** 定期檢查機制（多久檢查一次？）
- [ ] **第16點** 違約處理：違約通知怎麼發？
- [ ] **第17點** 終止租約條件（114年修正：房東終止門檻降低，需要「正當理由」）
- [ ] **第18點** 返還期限與流程

### 📋 **第五部分：程序與生效（第19-23點）**

- [ ] **第19點** 損害賠償計算方式
- [ ] **第20點** 爭議處理機制（仲裁？調解？）
- [ ] **第21點** 通知送達方式（line？Email？實體掛號？）
- [ ] **第22點** 契約份數（至少3份：房東1份、租客1份、預留1份）
- [ ] **第23點** 契約簽署日期與生效

## ⚠️ **4大核心風險 - 不要踩雷**

| 風險 | 症狀 | 解決方案 |
|------|------|--------|
| **電費超收** | 房東自定電價、不提供帳單 | ✅ 要求台電帳單、拒絕超過台電定價 |
| **無故終止** | 租到一半突然被趕出 | ✅ 確保3年租期保護（114年新增） |
| **違約扣款** | 房東扣押金、任意扣費 | ✅ 明確列出違約項目、逾期未繳期限 |
| **返還糾紛** | 遷出後押金永遠拿不到 | ✅ 30天內返還，超過應付利息 |

## 🔴 **秒殺方案：3個問題判斷契約合法性**

### 問題1：能否查閱完整台電帳單？
- ✅ **能** → 正常
- ❌ **不能 / 房東自定電費** → 違法，應拒簽

### 問題2：租期滿3年前，房東能隨時趕你出去嗎？
- ✅ **不能（除非有正當理由）** → 正常（114年新規）
- ❌ **能** → 違反最新法規，風險大

### 問題3：退租後押金多久內返還？
- ✅ **30天內** → 正常
- ❌ **「扣費後返還」或「沒期限」** → 黑名單房東，勿簽

## 🆘 **遇到問題怎麼辦？**

| 問題 | 應對 |
|------|------|
| 房東要求簽不合法條款 | 要求修改，寫信確認版本（留憑證） |
| 已簽署發現問題 | 訪問當地租賃協會／消費者保護委員會 |
| 電費異常高 | 查詢台電帳單、要求調查 |
| 房東無故終止 | 拒絕搬遷，聯繫法律援助 |

## 💬 **常見Q&A**

**Q: 合約沒有寫的，房東還能要求嗎？**
A: 不能。法律保護：「契約未記載，房東無權主張」。拒絕未在合約列出的費用。

**Q: 房東臨時要漲租？**
A: 除非合約到期，否則不能漲。如果無故漲租→聯繫消保委員會。

**Q: 我簽了不合法條款怎麼辦？**
A: 「不得記載事項」即使簽署也無效。可向消保委申請調解。

**Q: 房東不還押金？**
A: 過期30天→可申請消費調解或小額訴訟（5萬以下）。
