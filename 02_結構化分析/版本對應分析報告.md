## 📋 執行摘要

### 核心結論
109年範本在發布時已包含完整的23項應記載事項及10項不得記載事項，**整體符合度達 95%**。但由於法規在113年7月及114年4月經歷2次重大修正，範本中部分條款已**落後於現行法規**，特別是**電費計費方式（第6點）**和**承租人終止權（第18點）**。

| 🟡 格式性差異 | 3項 | 中風險 |
| 🟢 完全一致 | 18項 | 無風險 |

### 🔴 實質性差異（2項）

#### **第6點：租賃期間相關費用之約定（電費）** ⚠️ 高風險

**114年法規（113年7月8日修正，114年4月18日再修正）**：
```
(三)電費：
  □由出租人負擔。
  □由承租人負擔。
  □以用電度數計費者，每度電費不得超過該租賃標的電費單「當期每度平均電價」；
    如公共設施電費未向台灣電力股份有限公司申辦分攤併入租賃標的電費內者，
    出租人不得額外收取。
  □非以用電度數計費者，出租人所收取之每期電費總金額，不得超過該租賃標的
    電費單之每期電費總額。
```

**109年範本**：
```
(三)電費：
  □由出租人負擔。
  □由承租人負擔。
  (備註：如為分租房間且經雙方約定以用電度數計費者，依夏月每度__元整，
   非夏月每度__元整收取，但均不得超過台灣電力股份有限公司所定當月用電量
   最高級距之每度金額。)
  □其他：   。
```

**差異分析**：
- ❌ **舊版（109年）**：以「最高級距每度金額」為上限（約6-7元/度）
- ✅ **新版（114年）**：以「當期每度平均電價」為上限（約3-4元/度）
- ⚠️ **影響**：舊版允許房東收取遠高於實際成本的電費，新版保護承租人權益
- 🔥 **風險等級**：**高風險** - 可能導致爭議，房東超收電費違法

---

#### **第18點：承租人提前終止租約** ⚠️ 中高風險

**114年法規（114年4月18日修正）**：
```
租賃期間有下列情形之一者，承租人得提前終止租約，出租人不得要求任何賠償：
(一)租賃住宅未合於所約定居住使用，並有修繕之必要，經承租人定相當期限催告，
    仍不於期限內修繕。
(二)租賃住宅因不可歸責承租人之事由致一部滅失，且其存餘部分不能達租賃之目的。
(三)租賃住宅有危及承租人或其同居人之安全或健康之瑕疵；承租人於簽約時已明知
    該瑕疵或拋棄終止租約權利者，亦同。
(四)承租人因疾病、意外產生有長期療養之需要。
(五)因第三人就租賃住宅主張其權利，致承租人不能為約定之居住使用。
(六)承租人死亡後，其繼承人得終止租約。  ← 【新增】
```

**109年範本**：
```
(第十七條完全相同，但缺少第(六)款)
+ 另有獨立第三項：承租人死亡，其繼承人得主張終止租約，
  其通知期限及方式，準用前項規定。
```

**差異分析**：
- ⚠️ **格式差異**：新版將「繼承人終止權」整合為第6款
- ✅ **實質內容一致**：範本雖未列為第6款，但在第三項已明確規定
- 🟡 **風險等級**：**中風險** - 內容符合但格式不同，建議更新

## 四、版本升級建議清單

### 🔴 P0 - 必須立即修正（法律風險）

#### 1. **電費計費方式（第五條第三項）**
**現行條款**：
```
(三)電費：
  □由出租人負擔。
  □由承租人負擔。
  (備註：如為分租房間且經雙方約定以用電度數計費者，依夏月每度__元整，
   非夏月每度__元整收取，但均不得超過台灣電力股份有限公司所定當月用電量
   最高級距之每度金額。)
```

**建議修正為**：
```
(三)電費：
  □由出租人負擔。
  □由承租人負擔。
  □以用電度數計費者，每度電費不得超過該租賃標的電費單「當期每度平均電價」；
    如公共設施電費未向台灣電力股份有限公司申辦分攤併入租賃標的電費內者，
    出租人不得額外收取。
  □非以用電度數計費者，出租人所收取之每期電費總金額，不得超過該租賃標的
    電費單之每期電費總額。
```

**修正理由**：
- 符合113年7月8日修正版本
- 防止房東以「最高級距」名義超收電費
- 保護承租人權益，避免法律糾紛

---

#### 2. **新增電費資訊提供義務（第十條新增第四項）**
**建議新增**：
```
第十條 出租人之義務及責任
（第一、二、三項維持不變）

四、依第五條規定約定電費由承租人負擔者，出租人應提供承租人租賃標的之
    電費資訊。承租人亦得逕向台灣電力股份有限公司申辦查詢租賃期間之有關
    電費資訊。
```

**修正理由**：
- 符合113年7月8日修正版本
- 增加電費透明度，防止超收
- 賦予承租人查詢權

---

### 🟡 P1 - 建議修正（格式一致性）

#### 3. **承租人終止權格式調整（第十七條）**
**現行條款**：
```
第十七條第三項：承租人死亡，其繼承人得主張終止租約，其通知期限及方式，
準用前項規定。
```

**建議修正為**：
```
第十七條第一項新增第(六)款：
(六)承租人死亡後，其繼承人得終止租約。

（刪除原第三項）
```

**修正理由**：
- 符合114年4月18日修正版本
- 統一格式，更易閱讀
- 實質內容不變

#### 4. **條款編號微調**

## 八、結論與建議

### 核心結論

1. **整體符合度高**：109年範本在發布時**完整涵蓋23項應記載事項及10項不得記載事項**，基礎架構紮實。

2. **法規已迭代**：113年7月及114年4月的2次修正，主要針對**電費計費方式**及**承租人終止權**，範本未能同步更新。

3. **實務影響**：
   - 使用舊版電費條款可能導致**房東超收電費爭議**

   - 其他條款仍具高度參考價值
