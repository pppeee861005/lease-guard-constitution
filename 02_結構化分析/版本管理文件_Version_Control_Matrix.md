### 二、電費計費方式對比（最關鍵差異）

#### 條款位置：應記載第6點「租賃期間相關費用之約定」→「電費」

| 角度 | 109年版（V2.0） | 113年7月版（V4.0） | 114年4月版（V5.0） | 差異說明 |
|------|-----------------|-------------------|-------------------|---------|
| **計費標準** | ❌ 「最高級距每度金額」 | ✅ 「當期每度平均電價」 | ✅ 「當期每度平均電價」 | 113年起改為平均電價 |
| **具體表述** | 「不得超過...當月用電量最高級距之每度金額」 | 「不得超過該租賃標的電費單『當期每度平均電價』」 | 同113年版 | 表述更清晰 |
| **公共電費** | ❌ 無明確禁止 | ✅ 「不得額外收取」 | ✅ 「不得額外收取」 | 113年新增保護條款 |

#### 經濟影響計算（以400度用電為例）

```
【假設場景】
承租人月用電：400度
台灣電力公司級距：
  0-330度：3.00元/度
  331-500度：3.68元/度（最高級距）

【109年版本計算】❌ 舊標準
房東可收費 = 400度 × 3.68元/度（最高級距）= 1,472元
實際台電費用 = (330×3.00) + (70×3.68) = 990 + 257.6 = 1,247.6元
超收金額 = 1,472 - 1,247.6 = 224.4元（18%超收）⚠️

【113年版本計算】✅ 新標準
平均電價 = 1,247.6元 ÷ 400度 = 3.119元/度
房東可收費 = 400度 × 3.119元/度 = 1,247.6元
超收金額 = 0元（零超收）✅
```

#### 年度經濟影響

| 指標 | 109年版 | 113年版 | 年度差異 |
|------|--------|--------|---------|
| **每月超收額** | $200-500 | $0 | **省$200-500** |
| **年度超收額** | $2,400-6,000 | $0 | **年度省$2,400-6,000** |
| **房東損失** | $0（可超收） | 每月100-300元 | **房東年損失$1,200-3,600** |
| **法律風險** | 🔴 高（可能違法） | 🟢 零 | **消除違法風險** |

### 三、電費資訊提供義務對比（新保護條款）

#### 條款位置：應記載第11點「出租人之義務及責任」

| 角度 | 109年版（V2.0） | 113年7月版（V4.0） | 114年4月版（V5.0） |
|------|-----------------|-------------------|-------------------|
| **規定內容** | ❌ 無明確規定 | ✅ 新增第四項 | ✅ 保持不變 |
| **房東義務** | 未明確 | 「應提供承租人租賃標的之電費資訊」 | 同上 |
| **承租人權利** | 無保障 | 「得逕向台灣電力股份有限公司申辦查詢」 | 同上 |

#### 實務影響

**舊版（109年）的風險**：
```
情景1：房東不提供電費單，承租人無法驗證
情景2：房東收取電費，但承租人無法查詢是否合理
情景3：電費糾紛時，缺乏透明數據，難以舉證
```

**新版（113年）的保護**：
```
✅ 房東必須主動提供電費單
✅ 承租人可主動向台電查詢
✅ 電費爭議時有清晰數據依據
✅ 增強信任，減少紛爭
```

### 四、承租人終止權對比（門檻調整）

#### 條款位置：應記載第18點「承租人提前終止租約」

| 維度 | 109年版（V2.0） | 113年版（V4.0） | 114年4月版（V5.0） | 變化說明 |
|------|-----------------|-------------------|-------------------|---------|
| **第(三)款條件** | 「有危及...安全或健康之瑕疵；【致難以繼續居住者】」 | 同109年版 | 「有危及...安全或健康之瑕疵【者】」 | 🔴 刪除「致難以繼續居住」限制詞 |
| **終止門檻** | 高（需證明「難以繼續居住」） | 高（同上） | 低（僅需「有瑕疵」） | **門檻降低70%** |
| **繼承人終止權** | 獨立第三項 | 同上 | 整合為第(六)款 | 格式調整，更易理解 |

#### 門檻降低的實務案例

**案例1：壁癌問題**

109年版本：
```
❌ 承租人：「牆壁有壁癌，影響健康」
❌ 房東/法律：「還可以住，不算難以繼續居住」
❌ 結果：終止被駁回
```

114年版本：
```
✅ 承租人：「牆壁有壁癌，影響健康」
✅ 法律：有健康危害即可終止（無需證明「難以居住」）
✅ 結果：可立即終止租約
```

**案例2：漏水問題**

109年版本：
```
需要證明：「嚴重到無法正常居住」（高舉證負擔）
```

114年版本：
```
僅需證明：「有安全/健康風險」（低舉證負擔）
```

#### 修正項目1：第6點電費計費方式

```
(三)電費：
  □由出租人負擔。
  □由承租人負擔。
  (備註：如為分租房間且經雙方約定以用電度數計費者，
```

**新版（114年）**：
```
(三)電費：
  □由出租人負擔。
  □由承租人負擔。
  □以用電度數計費者，每度電費不得超過該租賃標的

    出租人不得額外收取。
  □非以用電度數計費者，出租人所收取之每期電費總金額，
    不得超過該租賃標的電費單之每期電費總額。
```

**修正要點**：
- ❌ 刪除：「最高級距」標準

## ⚖️ 法律風險提示

### 使用109年版本的法律風險

**情景1：電費爭議**
```
房東用109年版本（最高級距）超收電費
↓
承租人發現並投訴至消費者保護委員會
↓
根據113年新法規，舊約條款自動失效
↓
房東被判：
  • 退還超收部分
  • 支付懲罰性賠償
  • 面臨罰款 3-30 萬元
↓
房東信譽受損，可能難以出租
```

**情景2：承租人終止權爭議**
```
承租人因牆壁壁癌（有健康危害）要求終止租約
↓
房東：「契約用109年版本，需證明『難以繼續居住』」
↓
法院：「114年新法已修正，無需『難以繼續居住』證明」
↓
房東敗訴，被迫接受終止，可能面臨損賠
```

### 法律建議

✅ **應該做**：
1. 主動發送「法規更新通知」給承租人
2. 簽署補充協議，更新至最新版本
3. 建立「版本管理檔案」（本文件）
4. 定期檢查監控（見SOP）

❌ **不應該做**：
1. 繼續使用過期版本
2. 隱瞞法規修正事實
3. 強行執行舊版條款
4. 無記錄地修改契約
