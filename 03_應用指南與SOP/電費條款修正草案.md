# 📜 電費條款修正草案

**草案名稱**：住宅租賃契約範本電費條款修正草案
**修正範圍**：第6點（租賃期間相關費用之約定）、第11點（出租人之義務及責任）
**法律依據**：內政部113年7月8日台內地字第11302639334號公告
**草案日期**：2026年6月12日
**草案目的**：防止電費超收、保障承租人權益、提升電費透明度

---

## 📋 執行摘要

### 修正目的

**問題 A：電費計費方式滯後**
- 109年版本允許房東按「最高級距電價」計費（約6-7元/度）
- 實際承租人用電平均電價約3-4元/度
- 導致房東超收電費15-25%（年度超收$2,400-6,000）

**問題 B：缺少電費資訊提供義務**
- 承租人無法驗證房東電費計算
- 房東可隱瞞實際耗電度數
- 黑箱作業風險高，糾紛頻發

### 修正策略

1. **第6點修正**：將電費計費方式從「最高級距電價」改為「當期每度平均電價」
2. **第11點新增**：新增第四項「電費資訊提供義務」，強制房東提供電費透明資訊

### 第6點修正說明

#### 1. 電費計費公式（關鍵修正）

**修正前（109年版本）**：
```
計費上限 = 該月用電量最高級距電價

實務例子：
台電級距表（夏月）：
  - 0-330度：3.00元/度
  - 331-500度：3.68元/度
  - 501+度：4.39元/度

房東可按「最高級距」計費：
  承租人用400度 → 房東按3.68元/度計費
  收費 = 400 × 3.68 = 1,472元

實際台電費用：
  330 × 3.00 + 70 × 3.68 = 990 + 257.6 = 1,247.6元

房東超收 = 1,472 - 1,247.6 = 224.4元（18%超收）
```

**修正後（114年版本）**：
```
計費上限 = 當期每度平均電價 = 當月電費總額 ÷ 當月實際用電度數

實務例子：
同樣承租人用400度

台電當期平均電價：
  平均電價 = 1,247.6 ÷ 400 = 3.119元/度

房東計費方式（新標準）：
  收費 = 400 × 3.119 = 1,247.6元

超收金額 = 0元（完全相符，零超收）
```

#### 2. 法律依據

**主要法規**：
- **內政部113年7月8日公告**（台內地字第11302639334號）
- **生效日期**：113年7月15日
- **適用範圍**：所有住宅租賃契約（含既有合約修正）

**法規原文**：
> 以用電度數計費者，每度電費不得超過該租賃標的電費單「當期每度平均電價」

| 透明度 | ✅ 計費公式明確 | ✅ 黑箱風險消除 |

#### 4. 禁止項目（紅線清單）

**房東不能做的事**：

❌ **禁止1：按最高級距計費**
```
錯誤示例：
承租人用400度，房東按夏月最高級距4.39元/度計費
收費 = 400 × 4.39 = 1,756元
違法超收 = 1,756 - 1,247.6 = 508.4元（41%超收）
```

❌ **禁止2：預付電費制度**
```
錯誤示例：
房東要求「每月先繳1,500元電費，超過部分再補」
原因：先給錢再算度數，無法確保按平均電價計費
```

❌ **禁止3：公共設施電費分攤（未經台電核准）**
```
錯誤示例：
房東將電梯、走廊照明電費分攤給租戶
正確做法：
- 必須向台電申辦「公共設施電費分攤併入租賃標的」
- 取得台電核准後才能收取
- 否則出租人不得額外收取
```

❌ **禁止4：隱瞞台電電費單**
```
錯誤示例：
房東只告知「本月電費1,500元」，不提供台電電費單證明
原因：承租人無法驗證計算方式
```

#### 5. 承租人驗證方法

**步驟1：檢查電費單**
```
向房東索取：
✅ 台電電費單正本或影本
✅ 電費單應包含：用電度數、電費總額、計費期間
```

**步驟2：計算平均電價**
```
公式：當期每度平均電價 = 電費總額 ÷ 用電度數

實例：
電費總額 = 1,247元
用電度數 = 400度
平均電價 = 1,247 ÷ 400 = 3.1175元/度
```

**步驟3：向台電查證（獨立驗證）**
```
方法1：台電官網查詢
  - 登入台電網站（www.taipower.com.tw）
  - 使用「電費查詢」功能
  - 輸入電號或地址查詢

方法2：台電客服專線
  - 撥打1911（24小時服務）
  - 提供租賃地址或電號
  - 查詢該地址用電度數及電費

方法3：親臨台電服務處
  - 攜帶租約影本
  - 申請查詢租賃期間電費資訊
```

**步驟4：發現超收時的處理**
```
情況1：房東善意錯誤
  → 與房東溝通，提供新法規資訊
  → 要求按平均電價重新計算，退還超收部分

情況2：房東拒絕調整
  → 向崔媽媽基金會諮詢（02-2365-8140）
  → 向內政部不動產資訊平台申訴
  → 必要時向消保官檢舉或提起民事訴訟
```

### 第11點修正說明

#### 1. 新增第四項內容（關鍵新增）

**新增條款全文**：
```
第十條 出租人之義務及責任

（第四項）依第五條規定約定電費由承租人負擔者，出租人應提供承租人
          租賃標的之電費資訊。承租人亦得逕向台灣電力股份有限公司
          申辦查詢租賃期間之有關電費資訊。
```

**條款解析**：

**出租人義務**：
1. **提供電費資訊**：
   - 提供台電電費單正本或影本
   - 說明電費計算方式
   - 告知電號及查詢方式

2. **資訊提供時機**：
   - 簽約時：提供電號及前期電費參考
   - 每期收取電費時：提供當期台電電費單
   - 承租人要求時：隨時提供電費查詢方式

**承租人權利**：
1. **查詢權**：
   - 可向台電申請查詢租賃期間電費
   - 房東不得拒絕或阻止查詢

2. **驗證權**：
   - 可驗證房東收取的電費是否符合法規
   - 發現超收可要求退款

#### 2. 法律依據

**主要法規**：
- **內政部113年7月8日公告**（台內地字第11302639334號）
- **住宅租賃定型化契約應記載及不得記載事項第11點第4項**
- **生效日期**：113年7月15日

**法規原文**：
> 依第六點規定約定電費由承租人負擔者，出租人應提供承租人租賃標的之電費資訊。承租人亦得逕向台灣電力股份有限公司申辦查詢租賃期間之有關電費資訊。

#### 3. 實務影響

**對房東的影響**：

| 影響維度 | 新增義務 | 執行難度 | 法律風險 |
|---------|---------|---------|---------|
| 提供電費單 | ✅ 強制義務 | 🟢 低（只需影印） | 🔴 高（不提供違法） |
| 說明計費方式 | ✅ 強制義務 | 🟢 低（口頭或書面說明） | 🟡 中（不清楚易糾紛） |
| 允許台電查詢 | ✅ 不得拒絕 | 🟢 低（承租人自行辦理） | 🟢 低（拒絕違法） |

**對承租人的影響**：

| 影響維度 | 新增權利 | 使用頻率 | 保障效果 |
|---------|---------|---------|---------|
| 電費透明度 | ✅ 可要求查看電費單 | 🔴 每月 | ✅ 防止黑箱作業 |
| 獨立驗證權 | ✅ 可向台電查詢 | 🟡 有疑慮時 | ✅ 確保計費正確 |
| 法律保障 | ✅ 超收可主張返還 | 🟢 必要時 | ✅ 受法律明確保護 |

#### 4. 出租人應提供的資訊清單

**必須提供（強制）**：

✅ **電號資訊**
```
提供時機：簽約時
內容：租賃住宅的台電電號
用途：承租人向台電查詢使用
```

✅ **台電電費單**
```
提供時機：每期收取電費時
內容：台電電費單正本或影本（含用電度數、電費總額）
用途：承租人驗證計費正確性
```

✅ **計費方式說明**
```
提供時機：簽約時及收取電費時
內容：
  - 當期每度平均電價計算公式
  - 實際計費金額
  - 台電查詢方式
用途：承租人了解如何計算電費
```

**建議提供（非強制但降低糾紛）**：

📋 **電費計算表**
```
格式範例：

租期：2026年5月
用電度數：400度（依台電電費單）
台電電費總額：1,247.6元
當期平均電價：1,247.6 ÷ 400 = 3.119元/度

承租人應繳電費：
  方式1（按度數）：400 × 3.119 = 1,247.6元
  方式2（按總額）：1,247.6元

備註：計費方式符合114年法規，按「當期平均電價」計費
```

📋 **台電查詢方式說明**
```
內容：
1. 台電官網：www.taipower.com.tw
2. 台電客服：1911（24小時）
3. 租賃住宅電號：__________
4. 承租人可憑租約向台電申請查詢
```

#### 5. 承租人驗證清單

**簽約時檢查**：
```
□ 合約中是否載明「電費由承租人負擔」
□ 房東是否提供電號
□ 房東是否說明電費計費方式
□ 合約是否註明「按當期平均電價計費」
□ 房東是否告知台電查詢方式
```

**每期收電費時檢查**：
```
□ 房東是否提供台電電費單（正本或影本）
□ 電費單是否顯示：用電度數、電費總額、計費期間
□ 計算平均電價是否正確（電費總額 ÷ 用電度數）
□ 房東收取金額是否 ≤ 台電電費總額
□ 如有疑問，是否向台電查證
```

**發現問題時的處理**：
```
情況1：房東未提供電費單
  → 書面要求房東提供（保留證據）
  → 自行向台電查詢驗證
  → 房東持續拒絕→申訴或法律途徑

情況2：房東提供的電費單與台電查詢不符
  → 要求房東說明差異
  → 可能原因：電表分錶、公共設施分攤
  → 檢查房東是否有台電核准文件
  → 無核准文件→要求退還超收部分

情況3：房東阻止承租人向台電查詢
  → 房東行為違法（侵害查詢權）
  → 向內政部不動產資訊平台申訴
  → 向消保官檢舉
```
