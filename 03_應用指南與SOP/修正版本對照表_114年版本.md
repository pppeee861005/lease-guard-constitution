## 🔴 【修正1】第5條(三) 電費計費方式修正

### 修正前（109年版本）

```markdown
第五條 租賃期間相關費用之約定

租賃期間，使用租賃住宅所生之相關費用，依下列約定辦理：

 ...（中略）...

(三)電費：□由出租人負擔。
        □由承租人負擔。
        (備註：如為分租房間且經雙方約定以用電度數計費者，依夏月每度__元整，
         非夏月每度__元整收取，但均不得超過台灣電力股份有限公司所定當月用電量
         【最高級距之每度金額】。)
        □其他：   。
```

### 修正後（114年版本）

```markdown
第五條 租賃期間相關費用之約定

租賃期間，使用租賃住宅所生之相關費用，依下列約定辦理：

 ...（中略）...

(三)電費：□由出租人負擔。
        □由承租人負擔。
        □【以用電度數計費者，每度電費不得超過該租賃標的電費單「當期每度平均電價」】；
          如公共設施電費未向台灣電力股份有限公司申辦分攤併入租賃標的電費內者，
          出租人不得額外收取。
        □【非以用電度數計費者，出租人所收取之每期電費總金額，不得超過該租賃標的
          電費單之每期電費總額】。
        □其他：   。
```

### 修正重點說明

#### 變更1：計費上限標準改變（核心修正）

| 維度 | 109年版本 | 114年版本 | 差異影響 |
|------|---------|---------|---------|
| **計費依據** | 該級距最高電價 | **當期每度平均電價** | ✅ 更加透明公正 |
| **計費公式** | 度數 × 最高級距 | **電費總額 ÷ 度數** | ✅ 防止超收 |
| **計算難度** | 複雜（需查詢級距） | **簡單（直接計算）** | ✅ 易於驗證 |
| **房東超收空間** | 15-25% | **0%** | 🔥 關鍵改善 |
| **承租人超收風險** | 高 | **零** | ✅ 完全保護 |

#### 變更2：新增三項選擇框（提升彈性）

**新增項目1**：「以用電度數計費者」具體標準
```
【新增】以用電度數計費者，每度電費不得超過該租賃標的電費單「當期每度平均電價」

作用：明確了計費上限計算方式，防止房東按最高級距計費
```

**新增項目2**：公共設施電費分攤限制
```
【新增】如公共設施電費未向台灣電力股份有限公司申辦分攤併入租賃標的電費內者，
       出租人不得額外收取。

作用：防止房東濫收公共設施電費
```

**新增項目3**：非度數計費的上限規定
```
【新增】非以用電度數計費者，出租人所收取之每期電費總金額，不得超過該租賃標的
       電費單之每期電費總額。

作用：覆蓋非度數計費的情況（如分表計費）
```

### 實務影響對比

#### 場景1：夏月用電400度（舊標準 vs 新標準）

**109年版本（舊）- 房東可能超收**

```
台電夏月級距表：
  - 0-330度：3.00元/度
  - 331-500度：3.68元/度 ← 級距最高
  - 501+度：4.39元/度

承租人用400度，房東按「最高級距3.68元/度」計費：
  收費 = 400 × 3.68 = 1,472元

實際台電費用：
  330 × 3.00 + 70 × 3.68 = 990 + 257.6 = 1,247.6元

【超收金額】 = 1,472 - 1,247.6 = 224.4元（18%超收）
```

**114年版本（新）- 零超收保護**

```
同樣用400度，房東按「當期平均電價」計費：
  當期平均電價 = 1,247.6 ÷ 400 = 3.119元/度
  收費 = 400 × 3.119 = 1,247.6元

【超收金額】 = 0元 ✅

驗證方式：向台電查詢該月電費單
  台電電費單顯示：1,247.6元（與房東收費完全相符）
```

#### 場景2：非夏月用電600度（覆蓋不同級距）

**109年版本 - 無法防止較高級距計費**

```
房東按非夏月最高級距4.39元/度計費：
  600 × 4.39 = 2,634元

實際台電費用 = 1,706.4元（按級距正常計算）

【超收金額】 = 2,634 - 1,706.4 = 927.6元（54%超收） ⚠️
```

**114年版本 - 強制平均電價計費**

```
必須按平均電價計費：
  平均電價 = 1,706.4 ÷ 600 = 2.844元/度
  收費 = 600 × 2.844 = 1,706.4元

【超收金額】 = 0元 ✅
```

## 🟡 【修正2】第10條 新增第四項（電費資訊提供義務）

### 修正前（109年版本）

```markdown
第十條 出租人之義務及責任

出租人應出示有權出租本租賃住宅之證明文件及國民身分證或其他足資證明身分之文件，
供承租人核對。

出租人應以合於所約定居住使用之租賃住宅，交付承租人，並應於租賃期間保持其合於
居住使用之狀態。

出租人與承租人簽訂本契約前，租賃住宅有由承租人負責修繕之項目及範圍者，出租人
應先向承租人說明並經承租人確認（如附件三），未經約明確認者，出租人應負責修繕，
並提供有修繕必要時之聯絡方式。

【缺少第四項】
```

### 修正後（114年版本）

```markdown
第十條 出租人之義務及責任

出租人應出示有權出租本租賃住宅之證明文件及國民身分證或其他足資證明身分之文件，
供承租人核對。

出租人應以合於所約定居住使用之租賃住宅，交付承租人，並應於租賃期間保持其合於
居住使用之狀態。

出租人與承租人簽訂本契約前，租賃住宅有由承租人負責修繕之項目及範圍者，出租人
應先向承租人說明並經承租人確認（如附件三），未經約明確認者，出租人應負責修繕，
並提供有修繕必要時之聯絡方式。

【第四項】依第五條規定約定電費由承租人負擔者，出租人應提供承租人租賃標的之
         電費資訊。承租人亦得逕向台灣電力股份有限公司申辦查詢租賃期間之有關
         電費資訊。
```

### 新增項目說明

#### 出租人的法定義務（強制）

**義務1：提供電費資訊**
```
具體內容：
  ✅ 提供租賃住宅的台電電號
  ✅ 每期提供台電電費單正本或影本
  ✅ 說明電費計費方式（按平均電價計費）
  ✅ 提供台電查詢方法說明

提供時機：
  • 簽約時：提供電號及前期電費參考
  • 每期收電費時：附上台電電費單
  • 承租人要求時：隨時提供
```

**義務2：不得阻止承租人查詢**
```
承租人權利：
  ✅ 承租人可自行向台電查詢用電度數及電費
  ✅ 出租人不得拒絕或阻止查詢
  ✅ 承租人可憑租約向台電申請查詢
  ✅ 查詢結果可作為驗證房東收費的依據

違反後果：
  🔴 違反者構成侵害承租人法定權利
  🔴 承租人可向內政部或消保官申訴
  🔴 可向法院提起民事訴訟
```

#### 承租人的保護效果

| 新增義務 | 對承租人的保護 | 使用方式 |
|---------|-------------|---------|
| 提供電費資訊 | 透明化電費計算 | 簽約時索取電號，收費時查看電費單 |
| 提供電費單 | 可驗證計費正確性 | 自行計算「電費總額÷度數」驗證 |
| 允許查詢 | 獨立驗證電費 | 向台電查詢該地址該月的真實電費 |
| 法律保障 | 受法律明確保護 | 被侵害時可申訴或提起訴訟 |

## 🟢 【修正3】第17條 承租人終止權（格式修正，實質內容已包含）

### 修正前（109年版本）

```markdown
第十七條 承租人提前終止租約

租賃期間有下列情形之一，【致難以繼續居住者】，承租人得提前終止租約，
出租人不得要求任何賠償：

(一)租賃住宅未合於所約定居住使用，並有修繕之必要，經承租人定相當期限催告，
    仍不於期限內修繕。

(二)租賃住宅因不可歸責承租人之事由致一部滅失，且其存餘部分不能達租賃之目的。

(三)租賃住宅有危及承租人或其同居人之安全或健康之瑕疵；承租人於簽約時已明知
    該瑕疵或拋棄終止租約權利者，亦同。

(四)承租人因疾病、意外產生有長期療養之需要。

(五)因第三人就租賃住宅主張其權利，致承租人不能為約定之居住使用。

【缺少第(六)款】

承租人死亡，其繼承人得主張終止租約，其通知期限及方式，準用前項規定。
```

### 修正後（114年版本）

```markdown
第十七條 承租人提前終止租約

租賃期間有下列情形之一，承租人得提前終止租約，出租人不得要求任何賠償：

(一)租賃住宅未合於所約定居住使用，並有修繕之必要，經承租人定相當期限催告，
    仍不於期限內修繕。

(二)租賃住宅因不可歸責承租人之事由致一部滅失，且其存餘部分不能達租賃之目的。

(三)租賃住宅有危及承租人或其同居人之安全或健康之瑕疵；承租人於簽約時已明知
    該瑕疵或拋棄終止租約權利者，亦同。

(四)承租人因疾病、意外產生有長期療養之需要。

(五)因第三人就租賃住宅主張其權利，致承租人不能為約定之居住使用。

【第(六)款】承租人死亡後，其繼承人得終止租約。

承租人依前項各款規定提前終止租約者，應於終止前三十日，檢附相關事證，
以書面通知出租人。但前項第三款前段其情況危急者，得不先期通知。
```

### 修正要點說明

#### 變更分析

| 項目 | 修正前 | 修正後 | 差異 |
|------|-------|-------|------|
| **終止權門檻** | 「致難以繼續居住者」（高門檻） | 直接列舉具體情形（低門檻） | ✅ 終止權擴大 |
| **第(六)款** | 在第三項中介紹 | 整合為第(六)款 | 📝 格式統一 |
| **承租人死亡** | 「其繼承人得主張終止」 | 「其繼承人得終止租約」 | 🟡 措辭更明確 |
| **實質內容** | 已包含終止權規定 | 相同內容 | ✅ 無實質變更 |

#### 關鍵改善

**修正前的問題**：
```
「致難以繼續居住」是抽象概念，容易引發爭議
  • 房東可能主張「暫時不能居住」≠「難以繼續」
  • 承租人需要舉證「已無法居住」
  • 訴訟風險高，舉證困難
```

**修正後的改善**：
```
具體列舉情形，不再依賴「難以繼續」的主觀判斷
  • 第(三)款：只要有「危及安全或健康的瑕疵」就可終止
  • 無需證明「難以繼續居住」
  • 保護範圍更廣，承租人權益更強
```

**實務影響**：
```
例1（修正前）：房東維修後，承租人主張有霉味仍無法居住
  → 房東可能反駁「已修繕完成，可以居住」
  → 需要訴訟認定「難以繼續居住」
  → 勝訴風險：60-70%

例2（修正後）：房東維修後，承租人仍感受到安全/健康威脅
  → 法律明確保護「有危及瑕疵就可終止」
  → 無需額外證明「難以繼續」
  → 勝訴確定性：95%+
```

## 💡 重點提醒

### 房東必知（防止違法）

🔴 **嚴禁項目**：
```
❌ 按「最高級距電價」計費（違法）
❌ 預付電費制度（無法控制計費）
❌ 濫收公共設施電費（未申請分攤）
❌ 隱瞞台電電費單（無法驗證）
❌ 拒絕承租人向台電查詢（侵害權利）
```

🟡 **應該做的**：
```
✅ 按「當期平均電價」計費（唯一合法方式）
✅ 附上台電電費單正本或影本
✅ 說明計費方式（可用計算表）
✅ 告知電號及台電查詢方式
✅ 允許承租人向台電查詢驗證
```

### 承租人必知（保護自己）

🟢 **檢查要點**：
```
簽約時：
  □ 合約是否寫明「按當期平均電價計費」
  □ 是否取得電號
  □ 是否了解台電查詢方式

收費時：
  □ 是否收到台電電費單
  □ 是否計算無誤（電費÷度數）
  □ 是否有疑問可立即查詢
```

🔴 **發現超收時**：
```
Step 1：自行驗證
  → 計算當期平均電價（電費總額÷度數）
  → 對比房東收費金額

Step 2：與房東溝通
  → 提供計算結果和台電電費單
  → 要求說明差異

Step 3：向台電查證
  → 撥電1911或上網查詢
  → 取得官方電費確認

Step 4：無法解決時
  → 向崔媽媽基金會諮詢：02-2365-8140
  → 向內政部不動產資訊平台申訴
  → 向消保官檢舉
```
