## 📋 第19項：履行本契約之通知

### 法律要求（114年版本）

**法規依據**：住宅租賃定型化契約應記載事項第19點

**核心規定**：
```
雙方履行本契約之通知,應以書面或雙方約定之方式為之,
並明確約定送達地址及方式。
```

**必要記載內容**：
1. 通知方式（書面郵寄/電子郵件/簡訊/其他）
2. 送達地址（郵寄地址/Email/手機號碼）
3. 送達視為完成之時點
4. 地址變更通知義務
5. 無法送達之處理方式

### 風險提示

#### 房東常見違法方式
- ❌ 未約定通知方式（口頭通知爭議）
- ❌ 僅約定單一通知方式（對方未收到時無法證明）
- ❌ 未約定送達地址（無法有效通知）
- ❌ 未約定地址變更通知義務（搬家後無法聯繫）

#### 法律後果
- 🔴 通知無效,無法產生法律效力
- 🔴 終止租約、催繳租金等通知可能失效
- 🔴 舉證困難,糾紛時無法證明已通知

### 承租人自檢清單

**簽約前檢查**：
- [ ] 通知方式是否明確約定（至少2種以上）
- [ ] 送達地址是否正確（郵寄地址/Email/手機）
- [ ] 是否約定送達視為完成之時點
- [ ] 是否約定地址變更通知義務
- [ ] 是否有無法送達之備援機制

**簽約後注意**：
- [ ] 地址變更時,立即以書面通知房東
- [ ] 保留所有通知證據（Email截圖、掛號收據）
- [ ] 重要事項採雙重通知（郵寄+Email+簡訊）

**如收到房東通知**：
```
處理方式：
1. 確認通知內容真實性（撥電確認）
2. 保留通知證據（拍照、存檔）
3. 如有疑問,立即以書面詢問房東
4. 重要通知（如終止租約）應回覆確認
```

### 房東自檢清單

**簽約前準備**：
- [ ] 約定至少2種通知方式（郵寄+Email+簡訊）
- [ ] 確認承租人聯絡資訊正確
- [ ] 約定送達視為完成之時點
- [ ] 約定地址變更通知義務
- [ ] 準備通知範本（催繳、終止、修繕等）

**簽約後執行**：
- [ ] 重要通知採書面方式（掛號郵寄）
- [ ] 保留所有通知證據（掛號收據、Email紀錄、簡訊截圖）
- [ ] 無法送達時,採備援方式（其他通知管道）
- [ ] 記錄所有通知日期與內容

### 範本條款（114年標準版）

```markdown
## 第19項：履行本契約之通知

### 通知方式

雙方履行本契約之通知,得以下列方式為之：

1. ☑ 掛號郵寄至約定地址
2. ☑ 電子郵件
3. ☑ 手機簡訊
4. ☑ 現場張貼於租賃標的門口（公告送達）

### 送達時點

1. **掛號郵寄**：投郵後第3日視為送達
2. **電子郵件**：發送後即視為送達
3. **手機簡訊**：發送後即視為送達
4. **現場簽收**：簽收當日視為送達

### 地址變更通知義務

雙方地址、Email、手機號碼如有變更,
應於變更後7日內以書面通知他方。
```

### 實務案例

**✅ 良好範例**：
```
通知方式：掛號郵寄+Email+簡訊（三重通知）
送達地址：明確載明郵寄地址、Email、手機號碼
送達時點：郵寄第3日、Email即時、簽收當日
地址變更：7日內書面通知
證據保留：掛號收據+Email記錄+簡訊截圖

評價：✅ 通知有效,證據充分,符合法規
```

**❌ 錯誤範例**：
```
通知方式：口頭告知（未約定書面方式）
送達地址：未約定
送達時點：未約定

風險：
- 口頭通知無法舉證,法律效力薄弱
- 未約定送達地址,無法有效書面通知
- 糾紛時,房東舉證困難,通知可能無效
```

## 📋 第20項：條款疑義處理

### 法律要求（114年版本）

**法規依據**：住宅租賃定型化契約應記載事項第20點

**核心規定**：
```
本契約條款如有疑義時,
應為有利於承租人之解釋。
```

**必要記載內容**：
1. 疑義解釋原則（有利於承租人）
2. 法規依據（消費者保護法第11條）
3. 適用範圍（定型化契約條款）
4. 排除事項（個別磋商條款不適用）

### 風險提示

#### 房東常見違法方式
- ❌ 契約未載明疑義解釋原則
- ❌ 約定「疑義由房東解釋」（違法無效）
- ❌ 模糊條款利用房東優勢地位解釋
- ❌ 主張所有條款均經個別磋商（規避保護）

#### 法律後果
- 🔴 違反消費者保護法第11條
- 🔴 不利於承租人之條款無效
- 🔴 房東濫用解釋權可能導致契約無效
- 🔴 承租人可主張有利解釋（法院支持）

### 承租人自檢清單

**簽約前檢查**：
- [ ] 契約是否載明「疑義應為有利於承租人之解釋」
- [ ] 是否有「房東保留解釋權」條款（❌違法）
- [ ] 是否有模糊不清的條款（要求澄清）
- [ ] 個別磋商條款是否有書面記錄

**簽約後權利**：
- [ ] 遇到模糊條款時,主張有利解釋
- [ ] 保留證據（契約原文、爭議條款）
- [ ] 向崔媽媽基金會或消保官諮詢

**如遇爭議**：
```
處理方式：
1. 指出爭議條款（標註原文）
2. 主張有利於承租人之解釋
3. 提供法規依據（消保法第11條）
4. 要求房東接受有利解釋
5. 無法協商,向消保官申訴或提起訴訟
```

### 房東自檢清單

**簽約前準備**：
- [ ] 契約載明疑義解釋原則
- [ ] 確認所有條款清晰明確（避免疑義）
- [ ] 刪除「房東保留解釋權」條款
- [ ] 重要條款經個別磋商（保留書面記錄）

**簽約後理解**：
- [ ] 理解疑義解釋規則（模糊條款對己不利）
- [ ] 遇爭議時,優先協商而非堅持己見
- [ ] 接受法院可能採有利於承租人之解釋

### 範本條款（114年標準版）

```markdown
## 第20項：條款疑義處理

本契約條款如有疑義時,
應為有利於承租人之解釋。

**法規依據**：
消費者保護法第11條第2項規定：
「定型化契約條款如有疑義時,應為有利於消費者之解釋。」

**不得保留解釋權**：
❌ 「本契約如有疑義,由出租人解釋」（違法無效）
❌ 「出租人保留最終解釋權」（違法無效）
```

### 實務案例

**✅ 良好範例**：
```
契約條款：
「本契約條款如有疑義時,應為有利於承租人之解釋。」

所有條款明確清晰：
- 租金：新台幣壹萬伍仟元整（NT$15,000）
- 押金返還：遷出後14日內返還
- 修繕責任：非可歸責於承租人之損壞,由出租人負責

評價：✅ 疑義解釋原則明確載明,所有條款清晰
```

**❌ 錯誤範例（房東敗訴）**：
```
契約條款：
「本契約如有疑義,由出租人解釋。」

其他模糊條款：
- 租金：「約15K左右」
- 押金返還：「退租後看情況返還」

實際案例：
承租人退租後30日仍未收到押金,
房東主張「看情況」就是30日。

法院判決：
✅ 「房東保留解釋權」條款無效（違反消保法）
✅ 「看情況」應解釋為合理期限（14日內）
✅ 房東應立即返還押金並賠償利息

教訓：房東不得保留解釋權,模糊條款將被解釋為有利於承租人
```

## 📋 第21項：其他約定

### 法律要求（114年版本）

**法規依據**：住宅租賃定型化契約應記載事項第21點

**核心規定**：
```
本契約其他約定事項應明確記載,
不得違反強制或禁止規定,
不得損害承租人權益。
```

**必要記載內容**：
1. 公證約定（是否辦理公證、費用負擔）
2. 強制執行條款（是否約定逕受強制執行）
3. 特殊約定事項（寵物、裝潢、其他）
4. 不得記載事項檢查（確認無違法條款）

### 風險提示

#### 房東常見違法方式
- ❌ 加入不合法條款（違反應記載及不得記載事項）
- ❌ 限制承租人權利（如禁止提前終止）
- ❌ 強制公證但由承租人負擔全部費用
- ❌ 強制執行條款損害承租人（如未經催告即執行）

#### 法律後果
- 🔴 違法條款無效（不得記載事項）
- 🔴 損害承租人權益之約定無效
- 🔴 強制執行條款不當可能被法院撤銷
- 🔴 承租人可主張契約部分無效

### 承租人自檢清單

**簽約前檢查**：
- [ ] 第21項是否有不合理約定
- [ ] 公證費用負擔是否公平（建議各半）
- [ ] 強制執行條款是否損害權益
- [ ] 特殊約定是否違反法規或過度限制權利
- [ ] 是否有「不得記載事項」之違法條款

**重點檢查項目**：
```
❌ 禁止事項（不得記載）：
1. 限制承租人遷入戶籍
2. 不得提前終止租約
3. 承租人不得申報租賃費用支出
4. 應由出租人負擔之稅賦轉嫁予承租人
5. 免除或減輕出租人責任
6. 限制或剝奪承租人行使權利
7. 拋棄審閱期
8. 其他違反誠信原則之約定
```

**如發現不合法條款**：
```
處理方式：
1. 指出不合法條款（標註法規依據）
2. 要求刪除或修正
3. 拒絕簽署含不合法條款之契約
4. 如已簽署,主張該條款無效
```

### 房東自檢清單

**簽約前準備**：
- [ ] 確認第21項約定符合法規
- [ ] 刪除所有「不得記載事項」之條款
- [ ] 公證約定公平合理
- [ ] 強制執行條款符合規範
- [ ] 特殊約定不損害承租人權益

**公證約定檢查**：
```
✅ 合法約定：
- 雙方合意辦理公證
- 公證費用由雙方平均負擔或出租人負擔
- 明確約定公證項目（契約內容、強制執行）

❌ 不當約定：
- 強制公證但由承租人負擔全部費用
- 未經承租人同意即要求公證
- 公證費用過高（如超過租金5%）
```

### 範本條款（114年標準版）

```markdown

### 公證約定

□ 雙方合意辦理公證

- 公證費用由 ☑雙方平均負擔 □出租人負擔

❌ 承租人不得申報租賃費用支出
❌ 應由出租人負擔之稅賦轉嫁予承租人
```

### 實務案例

**✅ 良好範例**：
```
公證約定：雙方合意辦理公證,費用雙方平均負擔
特殊約定：允許飼養寵物、承租人得遷入戶籍、得申報租金費用
不得記載事項：無

評價：✅ 公證約定公平合理,特殊約定不損害承租人權益,無違法條款
```

**❌ 錯誤範例（嚴重違法）**：
```
其他約定：
- 承租人不得遷入戶籍（❌不得記載事項）
- 承租人不得提前終止租約（❌不得記載事項）
- 承租人不得申報租金費用（❌不得記載事項）
- 房屋稅由承租人負擔（❌不得記載事項）

實際案例：
承租人向消保官檢舉,消保官裁定上述條款全部違法無效,
裁罰出租人6萬元,要求修正契約。

教訓：「不得記載事項」絕對不可出現,違法條款將導致罰款
```

## 📋 第22項：契約及其相關附件效力

### 法律要求（114年版本）

**法規依據**：住宅租賃定型化契約應記載事項第22點

**核心規定**：
```
本契約自簽訂日起生效,
契約正本及其相關附件均為契約之一部分,
具有同等效力。
```

**必要記載內容**：
1. 契約生效日期
2. 契約份數及持有方
3. 附件清單及效力
4. 附件遺失或毀損之處理
5. 契約修訂程序

### 風險提示

#### 房東常見違法方式
- ❌ 生效日期不明確（爭議起算日）
- ❌ 附件效力未約定（附件失效）
- ❌ 僅出租人持有契約正本（承租人無法舉證）
- ❌ 附件清單不完整（重要附件遺漏）

#### 法律後果
- 🔴 生效日不明導致租金起算爭議
- 🔴 附件效力不明導致點交紛爭
- 🔴 承租人無契約正本無法舉證維權
- 🔴 附件遺失導致現況爭議

### 承租人自檢清單

**簽約時檢查**：
- [ ] 生效日期是否明確
- [ ] 是否持有契約正本（含所有附件）
- [ ] 附件清單是否完整（點交表、照片、設備清單）
- [ ] 所有附件是否雙方簽署
- [ ] 契約修訂程序是否約定

**簽約後保管**：
- [ ] 妥善保管契約正本及所有附件

## 📋 第23項：未盡事宜之處置

### 法律要求（114年版本）

**法規依據**：住宅租賃定型化契約應記載事項第23點

**核心規定**：
```
本契約如有未盡事宜,
悉依有關法令、習慣、誠實信用原則及平等互惠原則公平解決之。
```

**必要記載內容**：
1. 未盡事宜處理原則（法令、習慣、誠信、平等互惠）
2. 適用法令順序（民法、土地法、消保法等）
3. 爭議協商機制
4. 法院管轄約定

### 風險提示

#### 房東常見違法方式
- ❌ 約定「未盡事宜由房東決定」（違反平等互惠）
- ❌ 排除誠信原則或消保法適用
- ❌ 限制承租人法律救濟權利
- ❌ 約定不合理之法院管轄（增加承租人訴訟負擔）

#### 法律後果
- 🔴 違反誠信原則之約定無效
- 🔴 排除消保法適用之約定無效
- 🔴 不合理法院管轄約定可能無效
- 🔴 房東單方決定權約定無效

### 承租人自檢清單

**簽約前檢查**：
- [ ] 未盡事宜是否依法令、誠信原則處理（❌非「房東決定」）
- [ ] 是否排除消保法適用（❌不得排除）
- [ ] 法院管轄約定是否合理（建議租賃標的所在地）
- [ ] 是否保留法律救濟權利

**簽約後權利**：
- [ ] 遇未約定事項,主張依誠信原則處理
- [ ] 拒絕房東單方決定
- [ ] 保留訴訟、調解、仲裁等救濟權利

**如遇未盡事宜爭議**：
```
處理方式：
1. 檢視相關法令規定（民法、土地法、消保法）
2. 參考租賃習慣或判例
3. 主張誠實信用原則及平等互惠原則
4. 協商不成,尋求調解或訴訟
```

### 房東自檢清單

**簽約前準備**：
- [ ] 約定未盡事宜處理原則（法令、習慣、誠信、平等互惠）
- [ ] 不排除消保法適用
- [ ] 法院管轄約定合理（租賃標的所在地或雙方同意地點）
- [ ] 理解誠信原則及平等互惠原則

**未盡事宜處理原則**：
```
處理順序：
1. 依相關法令規定（民法、土地法、消保法等）
2. 依租賃習慣或行業慣例
3. 依誠實信用原則（不得濫用權利）
4. 依平等互惠原則（雙方權利義務對等）
5. 雙方協商達成共識
6. 協商不成,尋求調解或訴訟
```

**嚴禁項目**：
```
❌ 約定「未盡事宜由房東決定」
❌ 排除消保法或其他保護性法律適用
❌ 限制承租人法律救濟權利
❌ 約定過遠之法院管轄
```
