## 📋 第1項：契約審閱期

### 法律要求（114年版本）

**法規依據**：住宅租賃定型化契約應記載事項第1點

**核心規定**：
```
承租人應有至少3日以上之契約審閱期,
出租人不得以任何理由限制、拋棄或縮短審閱期。
```

**必要記載內容**：
1. 明確載明審閱期天數（至少3日）
2. 審閱期起算日（交付契約日）
3. 不得記載「拋棄審閱期」條款

### 風險提示

#### 房東常見違法方式
- ❌ 簽約當天直接簽署,未給審閱期
- ❌ 契約載明「承租人自願放棄審閱期」
- ❌ 審閱期少於3日（如「審閱期1日」）
- ❌ 口頭告知已給審閱期,但無書面記錄

#### 法律後果
- 🔴 違反者契約條款可能無效
- 🔴 承租人得主張未經充分審閱,契約不成立
- 🔴 消保官可裁罰出租人（罰款6萬-150萬元）

### 承租人自檢清單

**簽約前檢查**：
- [ ] 收到契約草案至簽約日是否至少相隔3日
- [ ] 契約中是否明確載明「審閱期3日」
- [ ] 契約中是否有「拋棄審閱期」條款（❌禁止）
- [ ] 是否有足夠時間仔細閱讀所有條款
- [ ] 是否有時間諮詢律師或專業人士

**如發現違規**：
```
處理方式：
1. 要求出租人提供至少3日審閱期
2. 拒絕簽署含「拋棄審閱期」條款的契約
3. 如已簽署,可主張契約無效（保留證據）
```

### 房東自檢清單

**簽約前準備**：
- [ ] 提前至少3日交付契約草案給承租人
- [ ] 契約中明確載明「審閱期3日以上」
- [ ] 確認未載有「拋棄審閱期」條款
- [ ] 保留交付契約草案的證據（如Email、簽收記錄）
- [ ] 確認承租人有充分時間審閱

**標準做法**：
```
步驟1：簽約前至少5日交付契約草案
步驟2：契約載明「本契約提供承租人審閱期5日」
步驟3：保留交付證據（Email時間戳、簽收單）
步驟4：簽約日再次確認承租人已充分審閱
```

### 範本條款（114年標準版）

```markdown
## 契約審閱權

本契約於民國___年___月___日交付承租人審閱,
承租人享有至少3日以上之契約審閱期。

審閱期間,承租人得充分閱讀契約條款,
並得諮詢律師或專業人士,
不受出租人催促或限制。

簽約日：民國___年___月___日
（自交付日起至少相隔3日）

✅ 承租人確認已充分審閱本契約所有條款
✅ 承租人確認審閱期符合法定要求（至少3日）
```

### 實務案例

**✅ 良好範例**：
```
2026年7月1日交付契約草案
2026年7月5日正式簽約
審閱期：5日（超過法定3日）
證據：Email交付記錄、簽收單
```

**❌ 錯誤範例**：
```
2026年7月1日當天交付契約並立即簽約

風險：契約可能無效,房東面臨罰款
```

## 📋 第2項:租賃標的

### 法律要求（114年版本）

**法規依據**：住宅租賃定型化契約應記載事項第2點

**核心規定**：
```
應明確記載租賃標的之完整資訊,包括:
1. 完整地址（含門牌號、樓層、專有部分編號）
2. 使用範圍（整層/套房/雅房/含車位）
3. 附屬設施清單（家電、家具）
4. 權利範圍（所有權、他項權利）
```

**必要記載內容**：
1. 標的物地址（精確至樓層、戶號）
2. 專有部分編號（如建號、地號）
3. 使用範圍詳述（含公共區域使用權）
4. 附屬設施詳細清單（品牌、數量、狀況）

### 風險提示

#### 房東常見違法方式
- ❌ 地址不完整（如「台北市某處房屋」）
- ❌ 使用範圍模糊（如「約50坪」）
- ❌ 附屬設施未列清單（退租時爭議）
- ❌ 未標註建號或地號（無法執行強制執行）

#### 法律後果
- 🔴 地址不明確導致契約無效或無法執行
- 🔴 使用範圍模糊導致使用權爭議
- 🔴 附屬設施未列清單,退租時無法舉證

### 承租人自檢清單

**簽約前檢查**：
- [ ] 地址是否完整（含樓層、門牌號、戶號）
- [ ] 是否載明專有部分編號（建號、地號）
- [ ] 使用範圍是否明確（整層/套房/雅房）
- [ ] 附屬設施清單是否詳盡（品牌、數量、狀況）
- [ ] 公共區域使用權是否約定（如停車位、頂樓）

**如發現問題**：
```
處理方式：
1. 要求出租人補充完整地址和建號
2. 要求明確標註使用範圍（附平面圖）
3. 要求列出附屬設施詳細清單（附照片）
4. 簽約後保留「遷入檢查表」（含現況照片）
```

### 房東自檢清單

**簽約前準備**：
- [ ] 準備完整地址資料（含建號、地號）
- [ ] 準備平面圖或使用範圍說明
- [ ] 列出附屬設施清單（品牌、型號、購買日期）
- [ ] 拍攝現況照片（至少20張）
- [ ] 確認所有權或出租權證明文件

**標準做法**：
```
步驟1：填寫完整地址（台北市大安區復興南路一段123號4樓之2）
步驟2：附上專有部分編號（建號：1234、地號：5678）
步驟3：標註使用範圍（套房含獨立衛浴、陽台、1個車位）
步驟4：列出附屬設施清單（冷氣2台Panasonic、冰箱1台Samsung等）
步驟5：附上現況照片（客廳、臥室、衛浴、廚房等）
```

## 📋 第3項：租賃期間

### 法律要求（114年版本）

**法規依據**：住宅租賃定型化契約應記載事項第3點

**核心規定**：
```
應明確記載租賃期間,包括:
1. 起始日期（年月日）
2. 終止日期（年月日）
3. 總租期（月數或年數）
4. 租金起算日
```

**必要記載內容**：
1. 起始日期（民國年月日）
2. 終止日期（民國年月日）
3. 租期總長（至少30日）
4. 租金起算日（遷入日）
5. 續約條款（選擇性）

### 風險提示

#### 房東常見違法方式
- ❌ 期限模糊（如「約一年」）
- ❌ 未約定租金起算日
- ❌ 自動續約條款不清楚
- ❌ 租期少於30日（違反法規）

#### 法律後果
- 🔴 期限模糊導致契約無效或難以執行
- 🔴 租金起算日不明導致爭議
- 🔴 自動續約條款不清導致提前終止爭議

### 承租人自檢清單

**簽約前檢查**：
- [ ] 起始日期是否明確（年月日）
- [ ] 終止日期是否明確（年月日）
- [ ] 租期是否至少30日
- [ ] 租金起算日是否明確約定
- [ ] 續約條款是否清楚（自動續約或重新簽約）

**如發現問題**：
```
處理方式：
1. 要求明確載明起始日期和終止日期
2. 確認租金起算日（建議為遷入日）
3. 約定續約方式（建議重新簽約,避免自動續約）
```

### 房東自檢清單

**簽約前準備**：
- [ ] 確定起始日期和終止日期
- [ ] 計算租期總長（確保至少30日）
- [ ] 確定租金起算日（建議為遷入日）
- [ ] 約定續約方式（建議重新簽約）

**標準做法**：
```
步驟1：明確起始日期（2026年7月1日）
步驟2：明確終止日期（2027年6月30日）
步驟3：計算租期總長（12個月）
步驟4：約定租金起算日（2026年7月1日,即遷入日）
步驟5：約定續約方式（期滿前30日通知,重新簽約）
```

### 範本條款（114年標準版）

```markdown
## 第3項：租賃期間

### 3.1 租賃期限
租賃期限自民國115年7月1日起至民國116年6月30日止,
共計12個月。

### 3.2 租金起算日
租金自民國115年7月1日（遷入日）起算。

### 3.3 續約條款
租賃期限屆滿前30日,任一方如欲續約,應主動通知對方。

雙方同意續約者,應重新訂立租賃契約,
不得以默示方式自動續約。

如未重新訂立租賃契約,視為不續約,
承租人應於期限屆滿時遷出並返還租賃標的。

### 3.4 期滿通知
出租人應於租賃期限屆滿前60日,
以書面通知承租人是否續約。

承租人應於收到通知後14日內回覆,
逾期未回覆視為不續約。
```

**✅ 良好範例**：
```

租金起算日：2026年7月1日（遷入日）
續約條款：期滿前30日通知,重新簽約

評價：✅ 明確清楚,無爭議
```

```
- 租期模糊,無法確定終止日期
- 租金起算日不明,可能爭議
- 自動續約可能導致承租人無法搬離
```

## 📋 第4項：租金約定及支付

### 法律要求（114年版本）

**法規依據**：住宅租賃定型化契約應記載事項第4點

**核心規定**：
```
應明確記載租金金額、支付期限、支付方式及遲延給付之處理,包括:
1. 每月租金金額（新台幣）
2. 繳納日期（每月幾日前）
3. 繳納方式（轉帳/現金/支票）
4. 逾期違約金標準（不得超過本金5%）

```

**必要記載內容**：

```markdown
✅ 懸掛照片或裝飾(不損害牆面)

### 10.4 回復原狀義務
租約終止時,承租人應將租賃標的回復原狀,
但雙方另有約定者,從其約定。

**需回復項目**:

2. 承租人更換之設備(需恢復原設備,如不同款式之馬桶)
3. 承租人改變之格局(需恢復原格局)

**不需回復項目**:
1. 正常粉刷或壁紙(不影響使用)
2. 合理裝修且提升價值(如更換新式馬桶)
3. 經出租人同意不需回復之項目

**折舊計算**:
裝修使用年限超過3年者,
回復原狀費用應按年折舊:

- 第2年:折舊40%
- 第3年:折舊60%
- 第4年:折舊80%
- 第5年以上:折舊100%(免回復)

### 10.5 費用負擔
**裝修費用**:由承租人負擔

**回復原狀費用**:
- 由承租人負擔
- 但已折舊部分得扣除
- 出租人要求承租人回復,應提供2家廠商報價

**回復原狀程序**:
1. 出租人列出需回復項目(附照片)
2. 提供2家廠商報價單
3. 承租人選擇自行回復或支付費用
4. 費用可從押金扣除(需提供收據)

### 10.6 裝修糾紛處理
如對裝修責任或回復原狀有爭議,
依下列方式處理:

**步驟1:檢視同意書**
- 確認當初同意書載明之裝修範圍
- 確認回復原狀約定

**步驟2:對比照片**

**步驟3:協商**

**步驟4:無法解決時**

- 保全證據(照片、同意書、報價單)
```

### 風險提示

#### 房東常見違法方式
- ❌ 拒絕減少租金(即使部分滅失)
- ❌ 要求承租人賠償天災損害
- ❌ 部分滅失後不修繕,仍要求全額租金

#### 承租人常見錯誤
- ❌ 不知可請求減少租金
- ❌ 無法舉證滅失程度
- ❌ 未保留證據(如災害照片)

#### 法律後果
- 🔴 拒絕減租違法,承租人可拒付差額
- 🔴 重大滅失,承租人可終止租約
- 🔴 天災損害,出租人不得要求承租人賠償

```markdown
## 第13項:租賃住宅部分滅失

### 13.1 部分滅失定義
租賃住宅因不可歸責於雙方之事由,
致部分滅失者,包括:

**滅失原因**:
1. 天災(地震、颱風、水災、火災)
2. 第三人行為(如鄰居火災波及)
3. 不可抗力事由(如戰爭、暴動)

**但不包括**:
❌ 可歸責於承租人之損壞
❌ 正常磨損或老化
❌ 出租人未盡修繕義務之損壞

### 13.2 請求減少租金權利
租賃住宅部分滅失,致影響居住使用者,
承租人得請求減少租金。

**減少租金計算標準**:

**1. 輕微滅失(減租10-20%)**:
- 單一設備故障(冷氣、熱水器)
- 影響部分使用(陽台受損)
- 不影響基本居住

**2. 中度滅失(減租30-50%)**:
- 多項設備故障
- 部分房間無法使用(如1間臥室)
- 影響正常居住但仍可居住

**3. 重大滅失(減租50%以上)**:
- 大部分無法使用(如2間臥室共損1.5間)
- 影響居住安全
- 幾乎無法居住

**減租計算範例**:
```
範例1:颱風導致陽台受損(佔總面積10%)
減租幅度:10-15%
租金15,000元 → 減租1,500-2,250元
應付租金:12,750-13,500元

範例2:火災導致1間臥室無法使用(佔總面積40%)
減租幅度:40%
租金15,000元 → 減租6,000元
應付租金:9,000元

範例3:地震導致房屋嚴重受損(需大規模修繕)
減租幅度:50-100%(或終止租約)
租金15,000元 → 減租7,500-15,000元
應付租金:0-7,500元(或終止租約)
```

承租人請求減少租金,
應遵守下列程序:

**步驟1:通知出租人**

- 拍照存證(損壞範圍、程度)
- 說明滅失原因

**步驟2:評估滅失程度**
- 雙方共同評估
- 必要時委託專業鑑定

**步驟3:協商減租幅度**
- 依滅失程度協商
- 參考上述減租標準
- 書面記錄減租協議

**步驟4:修繕與恢復**
- 出租人安排修繕(依第9點)
- 修繕完成恢復原租金
- 減租期間:自滅失日至修繕完成日

### 13.4 重大滅失終止權
租賃住宅因不可歸責於雙方之事由,
致大部分滅失,不能達租賃之目的者,
承租人得終止租約。

**重大滅失認定標準**:
1. 滅失面積超過50%
2. 影響居住安全(如結構受損)
3. 修繕期間超過60日
4. 無法達成租賃目的(無法居住)

**終止程序**:
1. 承租人書面通知終止(3日內生效)
2. 雙方辦理遷出檢查
3. 出租人返還押金(扣除應扣項目)
4. 當月租金按日數計算

### 13.5 不可歸責雙方之處理
租賃住宅滅失係不可歸責於雙方者,
依下列方式處理:

**損害負擔**:
- 🟢 出租人負擔修繕費用
- 🟢 承租人不負賠償責任
- 🟢 天災損害由出租人承擔

**租金處理**:
- 部分滅失:減少租金(依13.2)
- 重大滅失:承租人得終止租約
- 終止前租金:按日數計算

**押金處理**:
- 終止租約:全額返還(扣除應扣項目)
- 不得以滅失為由扣押金
- 14日內返還

### 13.6 可歸責於承租人之處理
租賃住宅滅失可歸責於承租人者,
依下列方式處理:

**損害賠償**:
- 承租人負修繕費用
- 修繕期間租金照付
- 無法修繕:賠償重置費用

**終止租約**:
- 出租人得終止租約
- 承租人負違約責任
- 押金不退

**範例**:
```
承租人煮飯不慎引發火災:
- 可歸責於承租人
- 承租人負損害賠償(修繕費用)
- 修繕期間租金照付(不得減租)
- 出租人得終止租約
```

為降低滅失風險,建議:

**出租人**:
- 投保火災保險(建築物)
- 投保地震險
- 保額足夠重置成本

**承租人**:
- 投保租客火災責任險
- 投保動產保險(個人財物)
```

```markdown
- 繼承人可依本款終止租約
- 出租人不得要求違約金或賠償

### 18.2 通知期限及方式
承租人依前項各款規定提前終止租約者,
應於終止前30日,
檢附相關事證,以書面通知出租人。

**但**前項第(三)款前段(安全或健康瑕疵),
其情況危急者,得不先期通知。

### 18.3 相關事證要求
承租人終止租約時,應檢附相關事證:

- 第(一)款:催告函、未修繕事證
- 第(二)款:滅失照片、估價
- 第(三)款:瑕疵照片、鑑定報告(如需)
- 第(四)款:醫療診斷證明
- 第(五)款:第三人主張權利之證明
- 第(六)款:承租人死亡證明、繼承關係證明

### 18.4 出租人不得要求賠償
承租人依本條規定提前終止租約者,
出租人不得要求任何賠償或違約金。

如出租人拒絕承租人依法終止,
或要求違約金,構成違約,
承租人得請求損害賠償。

### 18.5 修正說明 ⚠️ 重要
**114年4月修正要點**:

1. **刪除「致難以繼續居住」限制**:
   修正前需證明「難以繼續居住」(高門檻)
   修正後只要符合法定情形即可(低門檻)

2. **第(三)款擴大保護範圍**:
   修正前:需證明「有瑕疵」且「難以繼續」

3. **新增第(六)款繼承人終止權**:

```

## 📋 第23項：未盡事宜之處置
