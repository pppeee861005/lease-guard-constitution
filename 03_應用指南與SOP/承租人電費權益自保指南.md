**發布日期**：2026年6月12日
**法律依據**：內政部113年7月8日公告、114年4月18日修正
**目標對象**：住宅租客/承租人

## 🚨 快速預警：你可能被超收了

### 舊規定下的超收風險

```
你用電400度，房東收你：1,472元
但台電的實際費用只有：1,247.6元
你被多收了：224.4元（18%超收！）

如果每月都這樣，一年超收：2,700元

舊規定（109年版本）允許房東按「最高級距」計費
  舊：度數 × 最高級距 = 超收
  新：電費總額 ÷ 度數 = 公正

114年新規定已經改變了！
```

### ✅ 新規定如何保護你

```
從2026年開始，新版法規保護你的方式：

1️⃣ 計費標準改變
   房東必須按「當期平均電價」計費
   不能按「最高級距」超收

2️⃣ 資訊透明化
   房東必須提供台電電費單給你
   你可以自己驗證計費是否正確

3️⃣ 獨立查詢權
   你可以自由向台電查詢電費
   房東不能阻止或拒絕

4️⃣ 法律保障
   違反新規定的房東可被檢舉、罰款、訴訟
```

## 📚 三分鐘快速理解

### 電費計費方式的根本改變

| 維度 | 舊版（109年）危險 | 新版（114年）安全 |
|------|---|---|
| **計費公式** | 度數 × 最高級距（❌危險） | 電費總額 ÷ 度數（✅安全） |
| **計費上限** | 無明確限制 | 明確為「當期平均電價」 |
| **超收風險** | 15-25%（高風險） | 0%（完全防止） |
| **驗證方式** | 困難（需查級距） | 簡單（直接除法） |
| **房東權力** | 房東決定計費方式 | 法律嚴格限制 |
| **承租人權利** | 無明確保障 | 明確受法律保護 |
| **查詢透明度** | 房東可隱瞞 | 房東必須提供資訊 |

### 核心公式差異

```
舊版（❌禁止）：        新版（✅必須）：
度數 × 最高級距 =       電費總額 ÷ 度數 = 平均電價
可能超收15-25%         100%正確無誤

舊：400度 × 3.68元 = 1,472元  ❌（超收）
新：1,247.6元 ÷ 400度 = 3.119元/度
    400度 × 3.119元 = 1,247.6元 ✅（正確）
```

## 🛡️ 承租人的五大新權利

### 權利1：電費計費須合規

**你的權利**：
```
房東必須按「當期平均電價」計費
計費公式：台電電費單上的「電費總額」÷「用電度數」

舉例：
  如果該月台電電費是1,247.6元，用電400度
  房東計算：1,247.6 ÷ 400 = 3.119元/度
  房東應收：400 × 3.119 = 1,247.6元

❌ 房東不能做的：
  • 按「最高級距」計費（例如3.68元/度）
  • 按「預估費用」先收費
  • 隨意增加「分攤費用」

✅ 你應該檢查的：
  • 收到計費單時，計算平均電價驗證
  • 發現超收時，立即要求說明
  • 無法解釋時，要求退款
```

### 權利2：要求房東提供電費資訊

**你的權利**：
```
房東必須提供以下資訊：

📋 提供內容：
  1. 租賃住宅的「台電電號」
     → 用於你向台電查詢

  2. 每月「台電電費單」正本或影本
     → 含用電度數、電費總額、計費期間

  3. 「電費計算方式」說明
     → 怎樣計費、如何驗證

  4. 「台電查詢方式」指引
     → 電話、網站、親臨等方式

⏰ 提供時機：
  • 簽約時：提供電號及查詢方式
  • 每月收費時：附上台電電費單
  • 承租人要求時：隨時提供

❌ 房東不能做的：
  • 拒絕提供電費單
  • 隱瞞電號
  • 只說「電費是X元」，不說為什麼
  • 阻止你查詢任何資訊

✅ 你應該做的：
  • 簽約時問清楚電號
  • 每月收費時檢查電費單
  • 有疑問時要求房東解釋
  • 發現隱瞞時，申訴房東
```

### 權利3：向台電獨立查詢電費

**你的權利**：
```
法律明確保護：「承租人亦得逕向台灣電力股份有限公司
           申辦查詢租賃期間之有關電費資訊」

這意味著：
  ✅ 你可以自由向台電查詢
  ✅ 房東不能拒絕或阻止
  ✅ 查詢結果是官方認證
  ✅ 可作為驗證房東計費的依據

🔍 三種查詢方式：

  方式1：台電客服電話
    → 撥1911（24小時）
    → 說出租賃地址或電號
    → 查詢該月用電度數和電費

  方式2：台電官網查詢
    → www.taipower.com.tw
    → 點「電子帳單」或「電費查詢」
    → 登入方式：電號 + 身分證字號
    → 可查詢每月的用電度數和電費

  方式3：親臨台電營業處
    → 攜帶租約影本和身分證
    → 向櫃台申請查詢該地址的電費
    → 當場或稍後收到查詢結果

❌ 房東不能做的：
  「你不用查」「我已經算過了」
  「自己查什麼意思，不相信我？」
  → 這些都是違法拒絕行為

✅ 如果房東阻止你查詢：
  1. 保留證據（簡訊、郵件、證人）
  2. 向內政部不動產資訊平台申訴
  3. 向消保官檢舉
  4. 必要時向法院訴訟
```

### 權利4：發現超收時要求退款

**你的權利**：
```
如果發現房東超收電費，你有權要求退款

📊 驗證超收的方法：

  Step 1：取得台電電費單（向房東要）
  Step 2：計算當期平均電價
    公式：電費總額 ÷ 用電度數 = 平均電價
    例如：1,247.6元 ÷ 400度 = 3.119元/度

  Step 3：對比房東收費
    房東應收 = 用電度數 × 3.119元
    如果房東收費 > 計算金額 = 超收

  Step 4：計算超收金額
    超收金額 = 房東收費 - 應收費用

✅ 發現超收時的處理：

  方案1：與房東溝通（成功率高）
    → 禮貌說：「我算了一下，似乎有差異」
    → 提供：計算表 + 台電電費單
    → 大多房東會承認錯誤並退款

  方案2：請房東說明（如有異議）
    → 要求房東解釋為什麼超收
    → 說明：「新法規要求按平均電價計費」
    → 給房東改正的機會

  方案3：向台電查詢驗證（確定無誤）
    → 撥1911向台電查詢該月電費
    → 台電查詢結果支持你的計算
    → 握有官方資料，立場堅強

  方案4：房東仍拒絕退款（最後手段）
    → 向內政部不動產資訊平台申訴
    → 向消保官檢舉（違反消費者保護法）
    → 向法院提起民事訴訟
    → 出示計算表、電費單、查詢紀錄
    → 法院通常會支持承租人

💰 經濟帳：
  退款100元      vs    訴訟成本
  要求小，容易接受        困難、費時

  ✅ 建議：先溝通，再考慮法律途徑
```

```
  4. 與房東的通訊記錄（簡訊、郵件）

```

## 🔍 如何驗證電費計費

### 簽約時的驗證清單

```
簽約前必檢查的事項：

□ 合約第5條(三)是否明確寫「按當期平均電價計費」
  ✅ 應該寫：「每度電費不得超過該租賃標的電費單
            『當期每度平均電價』」
  ❌ 不應該寫：「不得超過最高級距之每度金額」

□ 房東是否提供了電號
  ✅ 應該記下：電號____（用於台電查詢）

□ 房東是否說明了計費方式
  ✅ 應該理解：怎樣計算當期平均電價
  ❌ 如果房東說不清楚，要求書面說明

□ 房東是否提供了台電查詢方式
  ✅ 應該知道：
    • 台電客服：1911
    • 官網：www.taipower.com.tw
    • 親臨台電營業處

□ 是否簽字確認
  ✅ 務必簽名，表示你同意並了解計費方式

簽約時要問的問題：
  1. 「電費怎樣計費？」
  2. 「我可以向台電查詢嗎？」
  3. 「每月會提供電費單嗎？」
  4. 「如果有疑問你會怎樣處理？」
  5. 「前住戶的平均電費大概多少？」

房東的好答案 vs 危險答案：
  ✅ 好：「按台電電費單的平均電價，我會提供電費單給你驗證」
  ❌ 危險：「電費就是這樣收，不用問那麼多」
           「我已經用最優惠的方式計費了」
           「別人都沒問過這個問題」
```

### 每月收電費時的驗證

**收到電費帳單時，做這5步檢查**：

```
收到房東的電費帳單時：

Step 1：檢查附件
  □ 是否附有台電電費單？
  □ 電費單是否清晰可讀？
  □ 電費單是否包含「用電度數」和「電費總額」？

Step 2：記下關鍵數據
  用電度數：____度
  台電電費總額：____元
  計費期間：____年____月____日～____年____月____日

Step 3：自己計算平均電價
  公式：台電電費總額 ÷ 用電度數 = 當期平均電價

  例如：
  電費單顯示：電費1,247.6元，用電400度
  我的計算：1,247.6 ÷ 400 = 3.1190元/度

  驗證：400 × 3.119 = 1,247.6元 ✅

Step 4：對比房東收費
  房東要收：____元
  我計算應付：____度 × ____元/度 = ____元

  檢查：
  □ 金額是否一致？
  □ 計費方式是否正確（平均電價，非最高級距）？
  □ 是否有其他不明費用？

Step 5：發現問題時
  □ 有疑問時，請房東說明
  □ 房東無法解釋時，保留所有單據
  □ 向台電查詢驗證
  □ 確認超收後，要求退款

簽名前的最後檢查：
  □ 收費金額 = 用電度數 × 當期平均電價？
  □ 房東提供的計算是否清楚？
  □ 我完全理解計費方式了嗎？
  □ 簽名前做好一切驗證
```

### 發現超收時的驗證方式

**如果電費異常高，這樣驗證**：

```
情況1：「這月電費特別高」

驗證方式：
  Step 1：對比往月
    • 去年同月電費多少？
    • 最近幾月的平均電費？
    • 這月確實異常嗎？

  Step 2：考慮合理原因
    • 天氣特別熱（空調用電增加）？
    • 多人居住（人數增加）？
    • 添置新電器（冰箱、洗衣機）？
    • 房屋有故障（漏水、日光燈故障增加耗電）？

  Step 3：對比同類住宅
    • 問朋友相同坪數用電多少？
    • 與統計數據比較？

  Step 4：無法解釋的異常
    → 向房東要求詳細說明
    → 可能的原因：電表故障、房屋用電異常、計費錯誤

情況2：「房東計費似乎不對」

驗證方式：
  Step 1：計算當期平均電價
    例如：房東說電費1,500元，用電400度
    平均電價 = 1,500 ÷ 400 = 3.75元/度

  Step 2：查詢台電級距
    台電通常是：2.5～4元/度
    3.75元/度在正常範圍內嗎？
    (注：這只是粗略檢查，最精確的是向台電查詢)

  Step 3：向台電查詢該月實際電費
    撥1911或上網查詢
    查詢結果：台電實際電費____元，用電____度

  Step 4：對比房東收費
    台電實際平均電價：電費÷度數 = ____元/度
    房東計費：____元

    如果：房東收費 > 台電實際電費
    結論：房東超收，需退款

情況3：「懷疑房東按最高級距計費」

驗證方式：
  舊版最高級距通常是：4.39元/度（最高的夏月級距）

  計算：
    如果房東收費 = 用電度數 × 4.39元
    那就是在按最高級距計費（違法！）

  例如：
    房東說400度電費 = 1,756元
    計算：1,756 ÷ 400 = 4.39元/度ㄝ
    正好是最高級距！
    → 這是違法超收
    → 要求立即退款
    → 可申訴房東

實戰例子：

  ❌ 超收案例1：
    台電電費單：1,247.6元，用電400度
    房東收費：1,472元（按3.68元/度）
    超收：1,472 - 1,247.6 = 224.4元
    → 要求退款

  ✅ 正常案例：
    台電電費單：1,247.6元，用電400度
    平均電價：1,247.6 ÷ 400 = 3.119元/度
    房東收費：1,247.6元
    → 正確，無誤

  ❌ 超收案例2：
    房東只說「電費1,500元」
    你向台電查詢：實際電費1,350元，用電400度
    房東多收：1,500 - 1,350 = 150元
    → 要求退款
    → 申訴房東隱瞞資訊
```

## 📋 承租人自保清單

### 簽約前的準備

```
□ 看清楚合約第5條(三)的電費計費方式
□ 確認合約寫的是「當期平均電價」而非「最高級距」
□ 記下房東提供的電號
□ 了解台電的聯絡方式（1911、官網、營業處）
□ 詢問房東前幾個月的平均電費（預期成本）
□ 確認房東會提供電費單（書面確認最好）
□ 在簽名前確保完全理解計費方式
□ 建議簽約時拍照保存合約條款
```

### 簽約後的第一個月

```
□ 拿到電費帳單時，立即檢查是否附有台電電費單
□ 沒有的話，立即向房東要求補上
□ 計算當期平均電價，確認房東收費是否正確
□ 記下用電度數和電費總額（建立長期紀錄）
□ 如有疑問，立即向房東詢問
□ 如房東無法解釋，向台電查詢驗證
□ 保存所有電費單據（備查之用）
```

### 每月日常檢查

```
□ 收到電費帳單時，檢查是否附電費單
□ 快速計算確認金額是否正確
□ 用電度數是否符合預期
□ 與往月對比是否有異常
□ 保存每月的單據和計算紀錄
□ 每季對帳一次（檢查整季累計）
```

### 發現問題時的處理

```
□ 保留所有證據（電費單、計算表、通訊記錄）
□ 禮貌但堅定地向房東提出質疑
□ 提供詳細的計算表和對照資料
□ 給房東合理的說明期限（例如5天）
□ 如房東無法說明，向台電查詢驗證
□ 握有台電確認資料，向房東要求退款
□ 房東拒絕退款，申訴內政部或消保官
□ 必要時進行法律訴訟
```

## 🎓 常見問題Q&A

### Q1：電費怎樣才算「合理」？

**A**：看「當期平均電價」，而不是看單月金額。
```
不同季節用電不同，所以金額會變化：
  • 夏月（5-9月）：空調用電增加，電費較高
  • 冬月（11-3月）：用電較少，電費較低
  • 春秋（4月、10月）：最低，可能只有夏月的1/3

判斷是否合理的方式：
  ✅ 計算當期平均電價（電費÷度數）
  ✅ 對照台電級距（通常在2.5～4元/度）
  ✅ 對比往年同月（考慮用戶人數變化）

不要只看「金額」，要看「平均電價」！

例子：
  ❌ 錯誤想法：「5月電費1,300元，6月電費1,500元，上升了，可能被超收」

  ✅ 正確想法：
     5月：1,300 ÷ 400度 = 3.25元/度
     6月：1,500 ÷ 480度 = 3.125元/度
     結論：其實6月更便宜（因為度數多但單價低）
```

### Q2：房東不提供電費單怎麼辦？

**A**：這是房東的法定義務，拒絕就是違法。
```
步驟1：書面要求
  發簡訊或郵件：「請提供當月台電電費單」
  保留證據

步驟2：房東仍不提供
  → 向內政部不動產資訊平台申訴
  → 申訴理由：房東違反電費資訊提供義務

步驟3：你自己向台電查詢
  → 拿租約去台電營業處
  → 申請查詢該地址的電費
  → 自己掌握數據，房東隱瞞不了

步驟4：有了台電數據後
  → 對比房東收費
  → 發現超收，要求退款
  → 房東仍拒絕，申訴或訴訟

記住：房東不提供 = 隱瞞資訊 = 違法行為
      你有權利申訴和索賠
```

### Q3：房東說前任租客用電多少，用來預估我的電費，可以嗎？

**A**：不可以。必須按實際使用計費。
```
❌ 錯誤做法：
  房東：「前任租客用電300度，電費就按往年計算」
  問題：前任可能住法人數少，用電習慣不同
       不能代表你的用電情況

✅ 正確做法：
  房東：「按你實際使用，每月根據台電電費單計費」

法律規定：「根據該租賃標的電費單『當期每度平均電價』」
意思就是：用你當月的實際電費和度數計算，不能預估

堅持立場：
  「我的電費應該根據我的實際使用計算」
  「請提供台電電費單，按當期平均電價計費」
```

### Q4：如果房東按最高級距計費，該怎麼辦？

**A**：這是明確違法行為，有明確的救濟方式。
```
判斷方式：
  例如房東說：「電費400度 × 3.68元 = 1,472元」
  你算台電：「實際電費是1,247.6元」

  差價：1,472 - 1,247.6 = 224.4元
  房東是在按「最高級距」超收！

立即行動：
  Step 1：要求房東說明
    「房東，我對電費有疑問，能說明怎樣計算的嗎？」
    保留房東的回應

  Step 2：向台電查詢驗證
    「台電查詢結果，該月電費應為1,247.6元」

  Step 3：書面要求退款
    發郵件：「根據新規定和台電確認資料，
            要求你於5日內退款224.4元」
    保留副本

  Step 4：房東不退款
    → 向內政部不動產資訊平台申訴
    → 向消保官檢舉（違反消費者保護法）
    → 法院訴訟（提出台電查詢單據）

法律支持你：
  新規明確禁止「最高級距」計費
  你有明確的法律依據要求退款
  房東違法風險大，通常會退款
```

### Q5：怎樣向台電查詢電費？（詳細步驟）

**A**：三種方式，選最方便的。
```
方式1：台電客服電話 1911

  Step 1：撥打1911（24小時服務）
  Step 2：告訴客服人員：
    「我想查詢台北市文山區○○街123號的電費」
  Step 3：客服會問：
    「可以提供電號嗎？」或「提供身分證字號」
  Step 4：客服查詢後告訴你：
    「該月用電度數XXX度，電費XXX元」
  Step 5：記下數據，與房東對比

  好處：最快，即時得到答案
  缺點：沒有書面證據（但可請客服寄郵件確認）

方式2：台電官網查詢 www.taipower.com.tw

  Step 1：進入台電官網
  Step 2：找「電子帳單」或「電費查詢」
  Step 3：登入方式：
    • 電號 + 身分證字號 (推薦)
    • 或申請會員帳號
  Step 4：進入後，查看每月電費明細
    • 用電度數
    • 電費總額
    • 級距詳情
  Step 5：截圖保存（有書面證據）

  好處：24小時可查，有詳細明細，可截圖存檔
  缺點：需要電號或身分證字號

方式3：親臨台電營業處

  Step 1：準備文件
    • 身分證正本
    • 租約影本
    • 住址證明（租約可做證明）
  Step 2：找最近的台電營業處
  Step 3：告訴櫃台：
    「我想申請查詢租賃住宅的電費」
  Step 4：提供租約和住址
  Step 5：台電工作人員查詢後提供清單
    （這份清單最有效力，可用於訴訟）

  好處：官方直接提供，具有最高效力
  缺點：需要親臨，耗時較長

三種方式優先級：
  日常查詢 → 用官網（最快）
  需要立刻驗證 → 用電話（即時）
  需要法律證據 → 親臨營業處（最有效力）
```

### Q6：承租人可以拒繳超收的電費嗎？

**A**：可以，但要有明確證據和程序。
```
❌ 不建議直接拒繳，因為：
  • 房東可能訴訟追討
  • 你需要充分證據證明「超收」
  • 沒有程序可能被認為違約

✅ 正確做法：

  Step 1：證實超收（有書面證據）
    • 台電查詢單據
    • 計費計算表
    • 房東無法解釋

  Step 2：書面通知房東
    「根據台電查詢，該月電費應為1,247.6元，
    不是1,500元。我只支付1,247.6元。
    多收部分(250.4元)待你說明後退款。」
    保存副本

  Step 3：合理扣款
    「我已將正確的電費1,247.6元匯入帳戶，
    超收部分250.4元予以扣款，
    提供以下證據：
    • 台電查詢清單
    • 計費計算表」

  Step 4：房東若訴訟
    你可舉證：
    • 台電官方查詢資料
    • 清晰的計費計算
    • 合理的溝通過程
    法院通常會支持你

記住：
  前提是有官方證據（台電資料）
  才能正當地拒繳超收部分
  否則可能被認為違約
```
