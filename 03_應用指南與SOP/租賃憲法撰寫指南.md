## 🎯 撰寫目標與核心理念

### 終極目標
建立一份「**保護承租人、規範出租人、預防糾紛**」的現代租賃憲法。

### 核心理念
1. **合規性優先**：遵循 114 年 4 月最新修正法規
2. **透明化執行**：讓雙方都能清楚理解和驗證
3. **風險防火牆**：提前預防最常見的租賃糾紛
4. **可操作性**：每條都附實務檢查清單

### 三大發現的啟示

| 發現 | 啟示 | 對憲法撰寫的影響 |
|------|------|----------------|
| 🔴 電費條款風險 | 109年版本允許超收15-25% | **重點強化第6點電費條款**（500+字詳述） |
| 🟡 版本滯後性 | 5年修正4次，關鍵更新未納入 | **建立版本追蹤機制**（年度檢查） |
| 🟢 並行蜂群效率 | 並行執行可加速6倍 | **工作流優化**（多代理並行審查） |

## 📝 23點詳細撰寫框架

### 第1點：租賃標的
**核心要素**：
- 完整地址（含樓層、門牌號、專有部分編號）
- 使用範圍（整層/套房/雅房/含車位）
- 附屬設施清單（家電、家具）

**風險提示**：
- ❌ 地址不明確導致無法執行強制執行
- ❌ 使用範圍模糊導致爭議（如：是否含陽台）
- ❌ 附屬設施未列清單，退租時爭議

**撰寫範本**（100-150字）：
```
甲方（出租人）同意將坐落於【完整地址含樓層】之房屋全部/部分【專有部分編號】
及附屬設施【清單：冷氣X台、冰箱、洗衣機等】出租予乙方（承租人）作為住宅使用。

使用範圍包括：
□ 整層（含公共區域）
□ 套房（含獨立衛浴）
□ 雅房（共用衛浴）
□ 車位編號：____

附屬設施清單：
1. 冷氣 ___ 台
2. 冰箱 ___ 台
3. 洗衣機 ___ 台
4. 熱水器 ___ 台
5. 家具：【詳細列舉】
```

**實務例子**：
✅ 良好範例：「台北市大安區復興南路一段123號4樓之2（專有部分編號：A4-02），含冷氣2台、冰箱1台、獨立陽台」
❌ 錯誤範例：「台北市某處房屋一間」（地址不明、範圍不清）

---

### 第2點：租賃期限
**核心要素**：
- 起始日期（年月日）
- 終止日期（年月日）
- 總租期（月數/年數）
- 是否自動續約條款

**風險提示**：
- ❌ 期限模糊（如「約一年」）無法執行
- ❌ 未約定遷入日期，導致租金計算爭議
- ❌ 自動續約條款不清楚，導致提前終止爭議

**撰寫範本**（100-150字）：
```
租賃期限自民國___年___月___日起至民國___年___月___日止，共計___個月。

租賃期限屆滿前___日，任一方如欲續約，應主動通知對方；
雙方同意續約者，應重新訂立租賃契約。

如無重新訂立租賃契約，視為不續約，承租人應於期限屆滿時遷出。

租金起算日：民國___年___月___日（遷入日）
```

**實務例子**：
✅ 良好範例：「2026年7月1日起至2027年6月30日止，共計12個月；租金起算日為2026年7月1日」
❌ 錯誤範例：「大約一年左右」（無明確日期）

---

### 第3點：租賃用途
**核心要素**：
- 使用類型（住宅/營業/混合）
- 禁止用途清單
- 違反用途的處理方式

**風險提示**：
- ❌ 營業用途未約定，房東可隨時終止
- ❌ 禁止項目過於寬泛（如「不得有任何噪音」）不合理
- ❌ 違反用途無明確罰則

**撰寫範本**（100-150字）：
```
租賃標的僅供【住宅/營業/混合】使用。

承租人不得將租賃標的供作：
□ 違法使用（如賭博、毒品）
□ 高風險營業（如瓦斯行、化學品倉庫）
□ 影響公共安全的用途

承租人如擅自變更用途，出租人得：
1. 要求限期改善（___日內）
2. 改善未完成者，得終止租約
3. 請求損害賠償
```

**實務例子**：
✅ 良好範例：「僅供住宅使用，不得作為商業登記地址；如需營業登記，應事先書面徵得出租人同意」
❌ 錯誤範例：「不得有任何噪音」（標準過於嚴格，難以執行）

---

### 第4點：租金約定
**核心要素**：
- 每月租金金額（新台幣）
- 繳納日期（每月幾日前）
- 繳納方式（轉帳/現金/支票）
- 逾期加收違約金標準

**風險提示**：
- ❌ 租金金額未寫明幣別（新台幣）
- ❌ 繳納日期不明確（如「月初」）
- ❌ 違約金過高違反民法第250條（不得超過本金5%）

**撰寫範本**（150-200字）：
```
租金為每月新台幣【金額大寫】元整（NT$ ______），
應於每月【幾日】前繳納。

繳納方式：
□ 轉帳至出租人指定帳戶（戶名：___ 帳號：___）
□ 現金交付（出租人應出具收據）
□ 支票（抬頭：___）

逾期未繳者：
1. 逾期未滿5日：免加收違約金，但出租人得催告
2. 逾期5日以上：每逾1日加收租金____%違約金（不得超過5%）
3. 逾期30日以上：視為重大違約，出租人得終止租約

租金調整條款：
□ 租期內不調整
□ 第___年起，每年調整____%（不得超過消費者物價指數）
```

**實務例子**：
✅ 良好範例：「每月租金新台幣壹萬伍仟元整（NT$15,000），於每月5日前轉帳至指定帳戶；逾期5日以上，每日加收租金0.1%違約金」
❌ 錯誤範例：「租金15K，月初繳，逾期罰1000元」（金額不明確、違約金過高）

---

### 第5點：押金約定
**核心要素**：
- 押金金額（不得超過2個月租金）
- 繳納時間（簽約時/遷入前）
- 返還條件與期限（遷出後X日內）
- 扣除項目與標準

**風險提示**：
- ❌ 押金超過2個月租金（違反法規）
- ❌ 返還期限過長（建議14日內）
- ❌ 扣除標準不明確，導致爭議

**撰寫範本**（150-200字）：
```
押金為新台幣【金額大寫】元整（NT$ ______），
不超過2個月租金，應於【簽約時/遷入前】繳納。

押金返還條件：
1. 承租人遷出後，出租人應於___日內返還押金
2. 如有以下情形，出租人得扣除相應費用後返還：
   □ 積欠租金、水電費、管理費
   □ 租賃標的損壞（超過正常磨損）
   □ 清潔費（如未依約恢復原狀）

扣除標準：
- 損壞物品：依實際修繕費用扣除（需提供收據）
- 清潔費：不得超過新台幣____元
- 其他費用：需事先約定

出租人應於返還押金時，附上【扣除明細表】及相關收據。
```

**實務例子**：
✅ 良好範例：「押金新台幣參萬元整（NT$30,000，2個月租金），遷出後14日內返還；如有損壞，依實際修繕費扣除並提供收據」
❌ 錯誤範例：「押金5萬（3個月租金），退租時看情況扣」（超收+標準不明）

---

### 第6點：電費約定 ⚠️ **重點強化條款（500+字）**

#### 核心要素
- 電費計費方式（**必須按平均電價，禁止按級距最高價**）
- 電費資訊提供義務（113年7月新增）
- 承租人驗證權利（可向台電查詢）
- 禁止預付電費（先給錢再算度數）

#### 風險提示
- ❌ **按級距最高價計費違法**（109年舊版已廢止）
- ❌ **超收15-25%電費**（年度超收$2,400-6,000）
- ❌ **未提供電費資訊**（違反113年新規）
- ❌ **預付電費黑箱作業**（無法驗證）

#### 法規依據（114年4月最新）
```
「每度電費不得超過該租賃標的電費單『當期每度平均電價』」

計算公式：
當期每度平均電價 = 當月台電電費總額 ÷ 當月實際用電度數
```

#### 109年舊版 vs 114年新版對比

| 維度 | 109年版（已廢止） | 114年版（現行） | 差異 |
|------|----------------|---------------|------|
| 計費標準 | 級距最高電價 | 當期平均電價 | **關鍵差異** |
| 承租人用400度 | 可全部按3.68元/度 | 僅能按3.119元/度 | 超收224元/月 |
| 年度差異 | $2,688超收 | $0超收 | **-100%** |
| 資訊提供義務 | 無 | 必須提供 | **新增義務** |
| 驗證權利 | 無 | 可向台電查詢 | **新增權利** |
| 法律風險 | 中 | 零 | ✅ 合規 |

#### 實務案例詳解

**案例1：109年版本的超收陷阱**
```
租賃標的：台北市大安區套房
台電電費單（某月）：
  - 0-330度：3.00元/度 → 330 × 3.00 = 990元
  - 331-500度：3.68元/度 → 70 × 3.68 = 257.6元
  - 總電費：1,247.6元（400度）

房東計費方式（109年允許）：
  400度 × 3.68元/度（級距最高價）= 1,472元

承租人實際應付（114年規定）：
  當期平均電價 = 1,247.6 ÷ 400 = 3.119元/度
  400度 × 3.119元/度 = 1,247.6元

超收金額：
  1,472 - 1,247.6 = 224.4元/月
  年度超收：224.4 × 12 = 2,692.8元

法律後果：
  ❌ 超收部分違反消費者保護法
  ❌ 承租人可依114年法規主張權利
  ❌ 房東面臨退款 + 罰款風險
  ❌ 租賃關係惡化（電費糾紛最常見）
```

**案例2：正確做法（114年版本）**
```
同樣台電電費單（400度，1,247.6元）

房東計費方式（114年要求）：
  1. 計算平均電價：1,247.6 ÷ 400 = 3.119元/度
  2. 向承租人收費：400 × 3.119 = 1,247.6元
  3. 提供電費資訊：附上台電電費單影本
  4. 告知驗證方式：承租人可撥打1911向台電查詢

結果：
  ✅ 完全合法，零超收
  ✅ 透明化，承租人可驗證
  ✅ 避免糾紛，保護雙方
```

#### 撰寫範本（500+字標準版）

```markdown
## 第6點：電費約定（114年4月最新版）

### 6.1 計費標準 ⚠️ 法定紅線
電費由【出租人/承租人】負擔。

承租人負擔電費者，每度電費不得超過該租賃標的電費單「當期每度平均電價」。

**計算公式**（法定標準）：
當期每度平均電價 = 當月台電電費總額 ÷ 當月實際用電度數

**禁止事項**：
❌ 不得按「級距最高電價」計費（109年舊版已廢止）
❌ 不得預付電費（先給錢再算度數）
❌ 不得拒絕提供台電電費單影本
❌ 不得阻止承租人向台電查詢驗證

### 6.2 電費資訊提供義務（113年7月新增）
出租人應提供承租人租賃標的之電費資訊，包括：
1. **台電電費單影本**（每期電費單，遮蔽非必要個資後提供）
2. **實際用電度數**（當期總度數）
3. **台電電費總額**（當期應繳金額）
4. **平均電價計算過程**（總額 ÷ 度數 = 平均價）
5. **承租人應付金額**（承租人用電度數 × 平均價）

**提供方式**：
- 紙本：電費單影本 + 計算明細
- 電子：拍照傳送（LINE/Email）
- 時間：電費單到達後___日內通知

### 6.3 承租人驗證權利
承租人有權：
1. **查閱電費單原件**（出租人不得拒絕）
2. **向台電查詢驗證**（撥打1911客服專線）
   - 提供地址查詢當期用電度數
   - 驗證電費單真實性
3. **要求說明計算過程**（出租人有義務說明）
4. **拒付超收部分**（如發現計費錯誤）

### 6.4 電費繳納方式
承租人應於收到電費通知後___日內繳納。

繳納流程：
1. 出租人提供電費資訊（台電單 + 計算明細）
2. 承租人驗證計算正確性（可向台電查詢）
3. 承租人於___日內繳納
4. 出租人出具收據

逾期未繳：
- 逾期5日內：出租人得催告
- 逾期5日以上：每日加收應繳金額0.1%違約金
- 逾期30日以上：視為重大違約，出租人得終止租約

### 6.5 電費糾紛處理
如對電費計算有爭議：
1. 承租人可向台電查詢驗證（1911專線）
2. 雙方應於___日內協商
3. 協商不成，得申請調解或仲裁
4. 爭議期間，承租人應先依「台電當期平均電價」計算金額繳納

**爭議範例與處理**：

爭議情況A：房東拒絕提供電費單
處理方式：
1. 承租人可向台電查詢當期用電度數
2. 按台電資訊計算應付金額
3. 房東拒不提供視為違約，承租人得終止租約

爭議情況B：發現房東按級距最高價計費（109年舊版）
處理方式：
1. 承租人可主張按114年版本（平均電價）計費
2. 要求退回超收部分
3. 拒不退回者，可申請調解或訴訟

爭議情況C：懷疑電費單造假
處理方式：
1. 承租人撥打台電1911查詢驗證
2. 如確認造假，立即終止租約並報警（偽造文書罪）
3. 追討不當得利

### 6.6 電費相關附件
本契約應附：
□ 台電電費單影本（最近一期）
□ 電費計算公式說明
□ 台電查詢方式說明（1911專線）
□ 電費糾紛處理流程

**台電查詢方式**：
- 客服專線：1911
- 查詢項目：提供地址查詢當期用電度數、電費金額
- 開放時間：週一至週五 8:30-17:30

### 6.7 案例參考

**✅ 良好範例**（完全合規）
```
某月台電電費單：
  - 總電費：1,500元
  - 總度數：450度
  - 平均電價：1,500 ÷ 450 = 3.333元/度

承租人當月用電：300度（獨立電表）
應付金額：300 × 3.333 = 999.9元（四捨五入1,000元）

房東提供：
  ✅ 台電電費單影本
  ✅ 計算明細（1,500÷450=3.333，300×3.333=1,000）
  ✅ 台電查詢方式（1911專線）

承租人可驗證：撥打1911查詢地址用電度數
```

**❌ 錯誤範例**（違法超收）
```
某月台電電費單：
  - 0-330度：3.00元/度
  - 331-500度：3.68元/度（級距最高）
  - 總電費：1,247.6元
  - 總度數：400度

房東錯誤計費（109年舊版）：
  400度 × 3.68元/度 = 1,472元
  超收：1,472 - 1,247.6 = 224.4元（18%超收）

法律後果：
  ❌ 違反114年4月新法規
  ❌ 超收部分承租人可拒付
  ❌ 面臨退款 + 罰款風險
  ❌ 電費糾紛導致租賃關係破裂

### 第11點：出租人之責任 ⚠️ 含「電費資訊提供義務」（113年新增）

**核心要素**：
- 修繕義務（民法規定）
- 提供可居住環境
- **電費資訊提供義務**（113年7月新增）
- 不得妨礙承租人使用

**風險提示**：
- ❌ 未履行修繕義務（違反民法）
- ❌ **未提供電費資訊**（違反113年新規）
- ❌ 任意進入租賃標的（侵犯隱私權）

**撰寫範本**（200-250字）：
```
出租人應履行下列義務：

【修繕義務】（民法第429條）
1. 租賃標的有修繕必要時，出租人應負修繕責任
2. 修繕期間，承租人可請求減少租金
3. 如出租人怠於修繕，承租人得：
   - 自行修繕，費用由出租人負擔
   - 終止租約並請求損害賠償

【提供可居住環境】
出租人應確保租賃標的：
- 符合建築法規，無結構安全疑慮
- 符合消防法規，有滅火器、逃生路線
- 符合衛生標準,無污染、異味、害蟲

【電費資訊提供義務】⚠️ 113年7月新增
依第6點規定約定電費由承租人負擔者，出租人應：
1. 提供承租人租賃標的之電費資訊
   - 台電電費單影本（遮蔽非必要個資）
   - 實際用電度數
   - 台電電費總額
   - 平均電價計算過程
2. 在電費查詢截止日前通知承租人度數
3. 允許承租人查閱台電電費單原件
4. 提供台電查詢方式說明（1911專線）

【不得妨礙使用】
出租人不得：
- 任意進入租賃標的（需事先通知並經同意）
- 干涉承租人合法使用（如限制訪客）
- 單方變更契約條件（如突然調漲租金）

違反上述義務者：
承租人得請求履行、減少租金、終止租約或請求損害賠償。
```

**實務例子**：
✅ 良好範例：「出租人每月提供台電電費單影本及平均電價計算明細，承租人可撥打1911向台電驗證」
❌ 錯誤範例：「電費由房東統一收取，承租人無權查閱電費單」（違反113年新規）

### 第14點：遷入遷出檢查

**核心要素**：

**風險提示**：

- ❌ 單方認定損壞，無客觀標準

**撰寫範本**（150-200字）：
```
【遷入檢查】
承租人遷入時，雙方應共同檢查租賃標的現況，並填寫「遷入檢查表」，內容包括：

2. 損壞原因（可歸責於承租人/不可抗力/正常磨損）

【正常磨損標準】

- 牆壁輕微褪色
- 地板輕微刮痕（非深度刮傷）
- 家電正常老化（使用年限內）
- 門窗五金自然磨損
```

**實務例子**：
✅ 良好範例：「遷入時雙方共同檢查並拍照存證（含冷氣、冰箱、牆壁、地板等至少20張照片），遷出時比對照片判斷損壞責任」

### 第15點:房屋部分滅失

**核心要素**：
- 部分滅失的定義（如火災、地震）
- 租金減少請求權
- 終止租約條件

**風險提示**：
- ❌ 未約定部分滅失處理，承租人仍須全額繳租
- ❌ 未約定修復期限，承租人權益受損
- ❌ 滅失原因歸責不明確

**撰寫範本**（100-150字）：
```
租賃標的因不可抗力（如火災、地震、颱風）或不可歸責於承租人之事由，
致一部滅失者：

1. **租金減少請求權**：
   承租人得按滅失部分，請求減少租金。
   減少比例由雙方協商，協商不成得申請調解或仲裁。

2. **修復期限**：
   出租人應於___日內提出修復計畫，並於___日內完成修復。
   修復期間，承租人得請求減少租金或暫時遷出。

3. **終止租約條件**：
   如滅失部分過大（超過租賃標的____%），致不能達租賃目的者，
   承租人得終止租約，出租人應退還剩餘租金及押金。

4. **可歸責於承租人**：
   如滅失可歸責於承租人（如過失引發火災），
   承租人應負損害賠償責任，出租人得終止租約並沒收押金。
```

**實務例子**：
✅ 良好範例：「因地震導致房屋牆壁龜裂（滅失30%），承租人可請求減少租金30%，出租人應於30日內修復」

```

承租人有下列情形之一者,得提前終止租約,無須支付違約金：

### 18.1 法定終止事由（5種情況）

**情況1：房屋未合約定居住使用需修繕**
- 房屋有修繕必要,足以影響居住使用

- 承租人得提前終止租約

**情況3：房屋有危及安全/健康之瑕疵** ⚠️ 114年關鍵修正
- **舊版**：「租賃住宅有瑕疵危及承租人或其同居人之安全或健康,**致難以繼續居住者**」

**危及安全/健康之瑕疵範例**：
- 房屋漏水導致壁癌、發霉（危及健康）

- 瓦斯管線漏氣（危及安全）
- 結構龜裂、傾斜（危及安全）
- 消防設備不足（危及安全）

3. 爭議不成,得申請調解或仲裁
```

## 🔴 電費條款重點強化建議（基於發現1）

### 核心洞察回顧
- **109年版本允許按級距最高價計費** → 超收15-25%（年度$2,400-6,000）
- **114年版本要求按平均電價計費** → 零超收,完全合規
- **113年新增電費資訊提供義務** → 透明化,可驗證
- **電費糾紛佔租賃案件40%以上** → 最常見爭議源頭

### 強化策略（5個維度）

#### 1. 法規依據明確化
```
在第6點開頭明確標註：
「⚠️ 本條款依114年4月18日最新修正版本訂定」

並附上法規條文：
「每度電費不得超過該租賃標的電費單『當期每度平均電價』」
（內政部114年4月18日台內地字第1140261533號令修正）
```

#### 2. 計算公式視覺化
```
使用表格和案例詳解：

| 項目 | 數值 | 來源 |
|------|------|------|
| 當月台電電費總額 | 1,247.6元 | 台電電費單 |
| 當月實際用電度數 | 400度 | 台電電費單 |
| 當期每度平均電價 | 3.119元/度 | 計算：1,247.6÷400 |
| 承租人應付金額 | 1,247.6元 | 計算：400×3.119 |

✅ 正確計費（114年）：1,247.6元
❌ 錯誤計費（109年）：1,472元（超收224.4元）
```

#### 3. 驗證機制標準化
```
提供「承租人驗證三步驟」：

步驟1：查閱電費單
- 出租人應提供台電電費單影本（遮蔽非必要個資）
- 承租人確認「總電費」和「總度數」

步驟2：自行計算
- 計算平均電價：總電費 ÷ 總度數
- 計算應付金額：承租人用電度數 × 平均電價

步驟3：向台電驗證
- 撥打台電客服專線：1911
- 提供地址查詢當期用電度數
- 確認電費單真實性
```

#### 4. 糾紛預防文檔
```
生成「電費透明化協議」範本：

**出租人承諾**：
✅ 每月提供台電電費單影本
✅ 提供平均電價計算明細
✅ 允許承租人查閱電費單原件
✅ 告知台電查詢方式（1911）

**承租人承諾**：
✅ 收到電費通知後7日內繳納
✅ 如有疑問先向台電查詢驗證
✅ 合理使用電力,避免浪費

**雙方共識**：
✅ 按114年法規（平均電價）計費
✅ 透明化、可驗證、零超收
✅ 電費糾紛優先協商解決
```

#### 5. 反面教材警示
```
在第6點末尾添加「常見錯誤與法律後果」：

❌ 錯誤做法A：按級距最高價計費（109年舊版）
法律後果：
- 違反114年法規,超收部分無效

法律後果：
- 無法驗證實際用電

❌ 錯誤做法C：拒絕提供電費單

- 違反113年新規（電費資訊提供義務）
```
