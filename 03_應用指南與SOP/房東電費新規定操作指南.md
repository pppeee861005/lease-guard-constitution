# 🏠 房東電費新規定操作指南

**指南主題**：電費從「最高級距」改為「當期平均電價」——房東如何合規操作
**發布日期**：2026年6月12日
**法律依據**：內政部113年7月8日公告、114年4月18日修正
**目標對象**：住宅出租人/房東
**核心目標**：幫助房東理解新規定、正確計費、避免法律風險

---

## 🚨 快速警告

### 如果你還在用舊方式計費...

```
❌ 舊版（109年）計費方式：
   度數 × 最高級距電價

   例如：400度 × 3.68元/度 = 1,472元

   但實際台電費用只有：1,247.6元

   你可能被超收指控，面臨：
   🔴 退款要求 + 利息
   🔴 消費者保護法罰款
   🔴 租客流失與信譽損害
   🔴 可能的民事訴訟
```

### ✅ 新版（114年）合法方式：

```
✅ 新版（114年）計費方式：
   當期平均電價 = 台電電費總額 ÷ 用電度數

   例如：1,247.6元 ÷ 400度 = 3.119元/度
         400度 × 3.119 = 1,247.6元

   優勢：
   ✅ 完全合法，零風險
   ✅ 計費透明，承租人無異議
   ✅ 易於驗證，建立信任
   ✅ 長期受益，租客穩定度高
```

## 📚 三分鐘快速理解

### 舊版 vs 新版的核心差異

| 維度 | 109年版本（舊） | 114年版本（新） | 對你的影響 |
|------|---|---|---|
| **計費基礎** | 最高級距電價（6-7元/度） | 當期平均電價（3-4元/度） | 收入減少15-25% |
| **計費公式** | 度數 × 最高級距 | 電費總額 ÷ 度數 | 計算變簡單 |
| **房東超收空間** | 15-25% | 0% | 法律限制更嚴 |
| **承租人滿意度** | 低（易引發爭議） | 高（完全透明） | 租期穩定性提高 |
| **法律風險** | 中等（灰色地帶） | 零（明確規定） | 放心無憂 |
| **舉證難度** | 高（需對簿公堂） | 低（直接驗證） | 省時省力 |

### 最關鍵的變化：計費公式

```
舊版 ❌              新版 ✅
度數 × 最高級距  →  電費總額 ÷ 度數

實務例子：
舊版：400度 × 3.68元 = 1,472元（超收！）
新版：1,247.6元 ÷ 400度 = 3.119元/度
      400度 × 3.119元 = 1,247.6元（正確）
```

## 🛠️ 房東操作步驟

### 步驟1：取得台電電費單（簽約前+每月）

**簽約時**：
```
□ 致電台電：1911
□ 提供租賃住宅地址
□ 索取「前3-6個月的電費單」
□ 了解該地址的平均電費（幫助承租人預期）
□ 記錄電號（告知承租人用於查詢）
```

**關鍵信息**：
```
你需要從電費單上提取：
  ✅ 用電度數（影響計費）
  ✅ 電費總額（決定平均電價）
  ✅ 計費期間（核對是否完整月份）
  ✅ 電號（提供給承租人）
```

### 步驟2：理解「當期平均電價」的計算

**公式理解**：

```
當期平均電價 = 台電電費單的「電費總額」÷「用電度數」

例子1（夏月）：
  台電電費單顯示：電費1,247.6元，用電400度
  當期平均電價 = 1,247.6 ÷ 400 = 3.119元/度
  應收金額 = 400 × 3.119 = 1,247.6元 ✅

例子2（非夏月）：
  台電電費單顯示：電費1,706.4元，用電600度
  當期平均電價 = 1,706.4 ÷ 600 = 2.844元/度
  應收金額 = 600 × 2.844 = 1,706.4元 ✅

例子3（檢驗計費正確）：
  承租人用350度，你收取電費1,100元
  驗證：平均電價 = 1,100 ÷ 350 = 3.14元/度
  對照台電：實際平均電價 = 3.119元/度
  結果：你多收了0.021元/度 × 350度 = 7.35元
  應退款給承租人：7.35元
```

**台電級距表參考**（僅供理解，不用於計費）：

```
你不需要手動查級距，而是直接用台電電費單上的數字！

舊版方法（❌禁止）：
  查詢級距 → 找最高級距 → 按最高級距計費 → 可能超收

新版方法（✅正確）：
  收到台電電費單 → 用電費單上的總額÷度數 = 平均電價
  → 就是你應該收的金額
```

### 步驟3：每月收電費的正確流程

**簽約時**：
```
□ 在合約中勾選「承租人負擔電費」
□ 註明「按當期平均電價計費」
□ 提供電號及台電查詢方式
□ 承租人簽字確認（重要！）
```

**每月收電費時**：

```
Step 1：取得當月台電電費單
  → 等待台電寄單或上網查詢
  → 確認用電度數及電費總額

Step 2：計算當期平均電價
  → 計算公式：電費總額 ÷ 用電度數
  → 例如：1,247.6元 ÷ 400度 = 3.119元/度

Step 3：準備「電費計算表」（附給承租人）
  ┌─────────────────────────────────┐
  │ 2026年5月電費計算表              │
  ├─────────────────────────────────┤
  │ 用電度數：400度（依台電電費單）  │
  │ 台電電費總額：1,247.6元           │
  │ 當期平均電價：3.119元/度         │
  │                                  │
  │ 承租人應繳：400 × 3.119 = 1,247.6元│
  │ 或直接：台電電費總額 = 1,247.6元  │
  │                                  │
  │ 附：台電電費單影本               │
  │ 查詢方式：1911或www.taipower.com  │
  └─────────────────────────────────┘

Step 4：提供台電電費單給承租人
  → 正本或影本都可以
  → 承租人可驗證你的計算
  → 建立信任，減少糾紛

Step 5：告知承租人查詢方式
  → 「如有疑問，可撥1911查詢」
  → 「台電官網可查詢該地址的電費」
  → 「我不會阻止你查詢」
```

### 步驟4：避免犯的錯誤

#### ❌ 禁止行為1：按最高級距計費

```
錯誤方式：
  看台電級距表，找出該月最高級距（例如4.39元/度）
  按最高級距收費：400度 × 4.39元 = 1,756元
  實際台電費用：1,247.6元
  超收：508.4元（41%！）

後果：
  🔴 違反114年法規
  🔴 承租人可要求退款
  🔴 承租人可向消保官檢舉
  🔴 面臨罰款 + 訴訟
  🔴 信譽損害

正確做法：
  ✅ 直接用台電電費單上的「總額」
  ✅ 計算平均電價：1,247.6 ÷ 400 = 3.119元/度
  ✅ 收費：400 × 3.119 = 1,247.6元（完全正確）
```

#### ❌ 禁止行為2：預付電費制度

```
錯誤方式：
  「每月先繳1,500元電費，月底多退少補」

為什麼違法：
  你無法預先確定該月電費總額和度數
  承租人無法監督實際計費
  容易引發「多繳未退」的爭議

正確做法：
  ✅ 等台電電費單出來（通常月底）
  ✅ 提供電費單給承租人
  ✅ 計算平均電價，收取相應金額
  ✅ 承租人可向台電驗證
```

#### ❌ 禁止行為3：濫收公共設施電費

```
錯誤方式：
  「樓梯、走廊、大廳的電費分攤給所有住戶」
  「分攤電費：每戶100元」

為什麼違法：
  除非向台電申辦「公共設施電費分攤併入」
  否則出租人不得額外收取
  未申請的分攤收費 = 違法超收

正確做法：
  Step 1：檢查該物件是否有公共設施電表
  Step 2：向台電申請「公共設施電費分攤併入租賃標的電費」
  Step 3：取得台電核准文件
  Step 4：持核准文件向承租人說明
  Step 5：在合約中列明「公共設施電費包含在電費中」
  Step 6：按平均電價計費（已包含公共設施）

  如未申請：
  ❌ 公共設施電費只能由房東自己負擔
  ❌ 不能分攤給承租人
```

#### ❌ 禁止行為4：隱瞞台電電費單

```
錯誤方式：
  承租人要求查看電費單，你拒絕
  「我自己已經算過了，直接告訴你多少錢」

為什麼違法：
  新法明確要求房東「提供電費資訊」
  隱瞞電費單 = 隱瞞基本資訊
  承租人無法驗證你的計費是否正確
  構成「侵害承租人查詢權」

法律後果：
  🔴 違反新法規第10條第四項
  🔴 承租人可申訴、向消保官檢舉
  🔴 法院可判令你提供電費單
  🔴 可能賠償承租人損失

正確做法：
  ✅ 每期收電費時，附上台電電費單（影本可）
  ✅ 主動提供電號，方便承租人查詢
  ✅ 說明計費方式，提供計算表
  ✅ 承租人有疑問時，協助查證
  ✅ 態度配合，建立信任
```

#### ❌ 禁止行為5：阻止承租人向台電查詢

```
錯誤方式：
  承租人：「我想自己向台電查詢一下電費」
  房東：「不用查，我已經給你算過了」
       或「你查詢什麼意思，不相信我？」
       或「憑什麼要查？」

為什麼違法：
  新法明確保護「承租人得逕向台電查詢」
  房東無權拒絕或阻止
  拒絕 = 侵害法律明確保護的權利

法律後果：
  🔴 直接違反新法規第10條第四項
  🔴 構成「侵害承租人法定權利」
  🔴 承租人可向內政部申訴
  🔴 可向消保官檢舉、法院訴訟

正確做法：
  ✅ 主動提供電號
  ✅ 告訴承租人查詢方式（撥1911或上網）
  ✅ 承租人如有疑問，協助查證
  ✅ 如差異達成共識，主動調整
  ✅ 打造「透明計費」的信譽
```

### 案例3：發現承租人對計費有疑問時

**情境**：
```
你向承租人收取電費1,500元
承租人回覆：「上月台電電費只有1,350元，為什麼要多付150元？」
```

**処理步驟**：

```
Step 1：冷靜，不要防守
  → 這是承租人正常的查詢行為
  → 不是在攻擊你，而是想驗證
  → 新法規明確保護「電費透明」

Step 2：立即提供台電電費單
  → 「你說得好，我馬上提供電費單」
  → 提供該月正確的台電電費單

Step 3：共同驗算
  → 如果台電電費確實是1,350元
  → 你多收了150元是計費錯誤
  → 應主動說：「抱歉，我算錯了，退你150元」

Step 4：確認差異原因
  可能原因包括：
  • 月份混亂（上月vs本月）
  • 承租人查詢的電號與租賃住宅不符
  • 台電系統延遲（電費單尚未出）
  • 你的計算確實有誤

Step 5：書面確認
  → 發送簡訊或郵件確認：
    「經查證，5月電費應為1,350元，
     已更正，近期補退150元」
  → 保留對話紀錄（日後如有爭議的證據）

Step 6：防止再犯
  → 下月開始，提高驗算的準確度
  → 或提前提供電費單給承租人核對
```

**預防措施**：
```
✅ 從簽約起就說明清楚：
   「我會按台電電費單的平均電價計費」
   「你可以隨時驗證或向台電查詢」

✅ 主動提供計算表：
   每月附上「電費計算表」
   讓承租人可以立即驗證

✅ 定期對帳：
   「如果你對任何月份的計費有疑問，
    我很樂意和你一起檢查台電電費單」

✅ 建立信任：
   「為了避免誤會，我建議你也可以
    撥1911直接向台電查詢這個地址的電費」
```

## 📋 房東自檢清單

### 簽約前檢查

```
□ 合約第5條(三)是否明確寫「按當期平均電價計費」
□ 是否刪除了「不得超過最高級距」的舊文字
□ 是否在合約中提供了電號
□ 是否說明了「承租人可向台電查詢」
□ 承租人是否簽字確認（重要！）

簽字確認的好處：
  ✅ 承租人事先知道計費方式，不會之後才反悔
  ✅ 日後有爭議時，簽字可作為證據
  ✅ 降低法律風險
```

### 每月收電費時檢查

```
□ 台電電費單是否已取得（等了多久？）
□ 電費單上的「用電度數」是否正確
□ 電費單上的「電費總額」是否包含稅金
□ 計算平均電價時是否四捨五入（請到2-3位小數）
□ 計算表是否清晰易懂
□ 是否隨電費單附送台電電費單影本
□ 是否告知承租人查詢方式（1911或官網）

檢查計算：
  例：電費1,247.6元，用電400度
  平均電價 = 1,247.6 ÷ 400 = 3.1190元/度（保留4位小數）
  收費 = 400 × 3.119 = 1,247.6元 ✅
```

### 如有爭議時檢查

```
□ 你是否提供了台電電費單（正本或影本）
□ 你的計費方式是否按「平均電價」計算
□ 承租人是否可以自由向台電查詢
□ 你是否曾試圖阻止承租人查詢

如果三項都是「是」，你的立場很強：
  ✅ 你已遵守新法規
  ✅ 計費方式有依據（台電電費單）
  ✅ 承租人有驗證管道
  ✅ 即使訴訟也能勝訴

如果有任何「否」，趕快補救：
  🔴 立即提供電費單
  🔴 重新計算並解釋計費方式
  🔴 允許承租人向台電查詢
  🔴 如有誤差，主動調整
```

## 🎓 常見問題Q&A

### Q1：為什麼要改成「平均電價」？舊方式不行嗎？

**A**：新法規因為承租人權益保護而改變。
```
舊方式（最高級距）的問題：
  • 房東可能按級距最高價計費
  • 承租人無法預測電費會多少
  • 容易引發「超收」糾紛
  • 很難舉證誰對誰錯

新方式（平均電價）的優勢：
  • 完全透明，直接用台電數據
  • 承租人可驗證，無誤會
  • 計費客觀，無主觀空間
  • 法律明確保護，風險最低

從商業角度看：
  • 舊方式：短期收益多，長期糾紛多
  • 新方式：收益略減，但租客穩定，口碑好
  • 投資回報率：新方式長期勝過舊方式
```

### Q2：新版能不能按舊版計費，額外賠償承租人？

**A**：不建議。法律不允許，風險反而更大。
```
❌ 為什麼不行：
  • 法律明確禁止「按最高級距計費」
  • 即使你「主動賠償」，也構成違法行為
  • 承租人可能仍會檢舉你，引發罰款

✅ 正確做法：
  • 直接按「平均電價」計費
  • 該是多少就是多少
  • 無需「額外補償」
  • 完全合法、零風險
```

### Q3：如果承租人一直不相信我的計費，怎麼辦？

**A**：鼓勵他向台電查詢，這正是新法的目的。
```
Step 1：態度上配合
  「你有權向台電查詢，我支持你驗證」

Step 2：提供查詢方式
  • 台電客服：1911
  • 官網查詢：www.taipower.com
  • 親臨台電營業處

Step 3：告訴他查詢結果
  「查詢完後，你會發現你的電費和我收的完全一樣」

Step 4：持久觀察
  「下個月會更清楚，因為你可以每月驗證」

好處：
  ✅ 承租人自己驗證後會信任你
  ✅ 比你再三解釋更有說服力
  ✅ 新法的透明機制發揮作用
  ✅ 長期建立信譽
```

### Q4：承租人發現超收，我該怎麼辦？

**A**：立即承認並退款，別狡辯。
```
❌ 不要：
  「計費方式就是這樣，你得接受」
  「台電收費也不是完全準確」
  「反正你也沒向台電查詢」

✅ 應該：
  「你說得對，我算錯了」
  「抱歉給你增添麻煩」
  「我立即退款給你」
  「感謝你的提醒，我會更仔細」

好處：
  ✅ 承租人會感謝你的誠實
  ✅ 退款只是小金額，損失不大
  ✅ 換來長期的信任和穩定的租期
  ✅ 避免訴訟，省去律師費和時間

經濟帳：
  退款 100元   vs   訴訟成本 5,000-20,000元
  + 租客流失   vs   租期穩定
  + 信譽損害   vs   口碑良好
  = 絕對划算
```

### Q5：合約還沒改版怎麼辦？已簽的舊合約怎麼應對？

**A**：新法規有溯及力，舊合約也要照新標準。
```
已簽的舊合約：
  • 114年版法規適用於所有租期中的合約
  • 你必須改為按「平均電價」計費
  • 即使合約寫的是舊版內容

應對方案：
  Step 1：主動出擊
    → 書面通知承租人：
      「配合新法規修正，電費計費方式改為平均電價」
    → 提供計算表和說明

  Step 2：從下月開始執行
    → 「本月仍按舊方式結算，
        下月開始按新規定計費」

  Step 3：說明益處
    → 「新規定更透明，你可以向台電驗證」
    → 「避免日後爭議」

  Step 4：積極修改合約
    → 準備「合約補充協議」
    → 雙方簽字確認新的計費方式
    → 日後有依據可循

法律風險：
  ✅ 提前改變的房東：無風險
  ❌ 繼續用舊版計費的房東：高風險
```

### Q6：公共設施電費可以分攤給承租人嗎？

**A**：可以，但必須向台電申請並取得核准。
```
流程：
  Step 1：確認有無公共設施電表
    → 樓梯、走廊、大廳的電費
    → 是否有獨立電表計量

  Step 2：向台電申請分攤
    → 向台電申辦「公共設施電費分攤併入」
    → 取得台電核准文件

  Step 3：持文件說明承租人
    → 「公共設施電費已申請分攤」
    → 「包含在上述平均電價中」

  Step 4：無需單獨收費
    → 承租人已透過平均電價負擔
    → 不需額外收「公共設施費」

❌ 禁止項目：
  • 未向台電申請卻分攤電費
  • 名義為「維修費」或「代管費」私下分攤
  • 按戶頭數均等分攤
  • 任意估算分攤金額

✅ 只有申請核准的分攤才合法
```
