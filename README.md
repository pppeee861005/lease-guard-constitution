# 計劃14 - 租賃憲法專案

**台灣住宅租賃合同合規性完整指南**

> 計劃14 是計劃13「租約哨兵」的知識基礎。官方規範的結構化、版本管理、電費修正方案都從這裡來。

## 概述

此專案整合官方政策文檔、版本歷史追蹤、和電費條款修正方案，提供完整的租賃憲法撰寫工具和法規監控機制。

### 計劃14 在整體體系中的位置

```
官方租賃定型化契約應記載及不得記載事項（內政部）
  ↓
計劃14：結構化、版本管理、洞察提煉
  ↓
計劃13：動態工作流、實際檢查應用
  ↓
終用戶：獲得租約檢查報告
```

## 工作流程設計：L1 Subagents 並行資料蒐集

### 核心方法論

**計劃14 採用「Subagent 並行網路資料蒐集」工作流，這是一個可複用的範式：**

```
任務分解
  ↓
分發給多個 Subagents 並行執行
  ↓
聚合與結構化
  ↓
提煉核心洞察
```

### 三支 Subagent 的執行記錄

| Subagent | 任務 | 來源 | 結果 |
|---------|------|------|------|
| **L1-01** | 下載行政院公報 + 內政部官文 | 行政院消費者保護會 | 114年4月18日最新版本 |
| **L1-02** | 蒐集合約範本（113年版） | 內政部地政司、崔媽媽基金會 | 多版本對照 |
| **L1-03** | 追蹤版本歷史（105-114年） | 全國法規資料庫、內政部公告 | 4+ 主要版本修正記錄 |

**執行時間**：15 分鐘並行（vs 60 分鐘順序執行）
**信息容量**：30,000+ 字 + 5 份核心文檔

### 可複用的工作流設計原則

```
1️⃣ 任務獨立性
   - 每個 Subagent 的任務必須完全獨立
   - 無強依賴關係，可並行執行

2️⃣ 資訊來源多元化
   - 官方公告、開源資料庫、NGO 資源
   - 交叉驗證確保準確性

3️⃣ 結果聚合與提煉
   - 四蜂群執行 → 跨域洞察（電費、版本、並行）
   - 從「資料」升級為「決策支援」

4️⃣ 反饋迴圈
   - 計劃13 應用時發現的問題 → 更新計劃14 來源
   - 法規更新自動觸發 → 計劃13 規則庫升級
```

### 借鑑方向

**下一個專案若需「時效性資料結構化」可採用此範式：**

```
法規監控 → 法律諮詢 AI
教材版本管理 → 教育內容協作平台
訴訟判例追蹤 → 法律風險預警系統

```

**關鍵成功因素**：

✅ 洞察的可驗證性（雙引用強制制度）

## 快速開始

### 1️⃣ 撰寫租賃憲法（計劃13使用）
- 參考「租賃憲法撰寫指南.md」的23點大綱逐點撰寫
- **計劃13 W2 的 P0 任務**：3小時撰寫完整版本

### 2️⃣ 檢查電費條款（計劃13風險規則）

- 用於計劃13的風險檢測（Stage 4）

### 3️⃣ 監控法規更新
- 啟用「法規監控與更新SOP.md」的監控機制，定期檢查新版本
- 當法規更新時，自動通知計劃13更新規則

### 4️⃣ 版本診斷（計劃13版本識別）
- 使用「版本追蹤總表.md」的3步驟診斷工具確認當前合同版本
- 用於計劃13的 Stage 2
